# cleanup-station

Две задачи, один движок на каждую, обёртки под все ОС (один код — не три копии).

## 1. Снос и подготовка к чистой установке

`bin/cleanup.mjs` + `cleanup.sh` / `cleanup.ps1` / `cleanup.cmd`

Снимает агентов (omp/pi/opencode), скиллы по слоям, прошивки, расширения и
MCP-регистрации — чтобы поставить всё заново начисто.

```bash
bin/cleanup.sh plan            # что будет снято (ничего не трогает)
bin/cleanup.sh clean-all --yes # снести
pwsh -File bin/cleanup.ps1 plan -WhatIf
```
Правила безопасности зашиты в код: только домашний каталог, только известные
имена/ссылки, `clean-all` без `--yes` — план, данные на диске (персоны,
коллекция скиллов, репозитории) не трогаются никогда.

Чужое в домашнем каталоге — тоже: скиллы снимаются только там, где запись
ссылается на диск (копии и сторонние ссылки остаются — строка «оставляю» их
перечисляет), MCP — только серверы из каталога `mcp-station` (свои записи
остаются; каталога нет — шаг отказывается работать), чужой текст прошивки
не трогается; наша прошивка, рядом с которой лежит `.bak`, тоже остаётся
(строка «оставляю … реши руками»: чистить её вслепую нельзя). Поэтому
`center fresh` и `install.sh --reset` больше не сносят личные скиллы и свои
MCP-серверы. Разбор и таблица — [docs/RESET.md](docs/RESET.md).

## 2. Отчёт по мусору на диске данных

`bin/junk-report.mjs` + `junk-report.sh` / `junk-report.ps1` / `junk-report.cmd`

Только чтение: показывает кэши/сборку, свалки (`_dump`, `tmp`, `trash`), артефакты
прямо в корне диска и служебные файлы, с размерами и итогом.

```bash
node bin/junk-report.mjs             # отчёт
node bin/junk-report.mjs --json      # машинно
node bin/junk-report.mjs --strict    # rc=1 при находках (крон/CI)
node bin/junk-report.mjs --all       # заглядывать и в .venv/.git
```

Правило и разбор реального случая — [docs/HYGIENE.md](docs/HYGIENE.md):

> на диске данных живут данные и код; артефакты — в рантайме
> (`~/.cache/...`, `$XDG_STATE_HOME/...`).

## Тесты

```bash
bats tests/station.bats       # снос: план, слои, отказы, защита диска
bats tests/junk-report.bats   # отчёт: находки, --strict, .venv, rc=2
```
Оба набора — в песочнице (`BATS_TEST_TMPDIR`), реальные данные и домашний
каталог не трогаются.
