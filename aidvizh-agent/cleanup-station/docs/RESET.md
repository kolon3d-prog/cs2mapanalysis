# Разнос install / update / reset: что снимается, а что не трогается

Разбор 22.09. Установщик дистрибутива звал `center fresh --yes` безусловно — то есть на любой машине
делал «снос → установка». Снос при этом был шире, чем нужно: он снимал **всё содержимое слоёв скиллов**
(личные скиллы — без бэкапа) и **все записи `mcpServers`** в конфигах клиентов (с `.bak`, но всё равно
все: и свои, и наши). Кто руками добавил свой MCP-сервер или написал пару скиллов, терял их при
следующем запуске установщика.

Стало два независимых исправления: у установщика — три разных входа, у сноса — «чужое не трогаем».

## Три входа у установщика

| вход | что делает | чего не делает |
|---|---|---|
| `install.sh` / `install.ps1` без флагов | на пустой машине — `center fresh --yes`; на занятой машине без следа набора — `center fresh --yes --no-cleanup`: ставит рядом | на машине, где набор уже стоит (есть команда `center` в `~/.local/bin`), **ничего не сносит и не ставит**: объясняет про `--update`/`--reset` и выходит с кодом 1 |
| `--update` / `-Update` | `center update all` — обновляет на месте | не снимает и не переустанавливает с нуля |
| `--reset` / `-Reset` | `center fresh --yes` — снять наше и поставить заново | чужое не трогает |

«Среда уже есть» — это `~/.omp/agent`, `~/.pi/agent`, `~/.config/opencode` или `~/.agents/skills`.
Живые сценарии (пустой дом, занятый дом, оба флага, `--help`) прогнаны на заглушке центра под bash
и pwsh — см. «Проверка» ниже.

**Заселение рядом.** У `center fresh` есть `--no-cleanup`: тот же план, но шаг «снос прежнего»
пропускается — набор ставится на занятую машину, ничего не снимая. Чужое при этом не трогается:
`mcp-station` оставляет записи, которые не её, а прошивка персоны кладёт копию рядом (`.bak`).

## Что снос трогает, а что нет

`clean-all` (и `--reset` за ним) теперь снимает только своё:

| шаг | снимает | чужое |
|---|---|---|
| CLI | глобальные omp/pi/opencode | — |
| скиллы | записи, **ссылкой** ведущие на диск: коллекция, репозитории станций | копии, сторонние ссылки и личные скиллы остаются — строка «оставляю» их перечисляет |
| прошивки | файл, содержимое которого совпадает с одной из персон | любой правленый текст остаётся; если рядом лежит `<файл>.bak` — файл тоже остаётся, строка «реши руками» |
| расширения, шимы, локи, юниты | только наши имена и ссылки на диск | — |
| MCP | записи, имена которых есть в каталоге `mcp-station/catalog` (перед правкой — `.bak`) | свои серверы остаются; каталога нет — шаг честно отказывается работать |
| состояние, логины | только с `--state` / `--purge` | — |
| конфиги целиком | только `--configs` (спрашивает «уверены?») | — |

**Почему скиллы именно так.** Отличить свой скилл от чужого по имени нельзя, а признак «ссылка ведёт
на диск» — безошибочный: так ставят свои и `skills-station` (режим ссылок по умолчанию), и `spec-station`,
и `skills-hub`, и `camoufox-research`. Копии не трогаем сознательно: копия может быть чужой работой,
а наши копии вернёт `skills-station install all` (он заменяет записи на месте).

**Почему MCP по каталогу.** Каталог `mcp-station` — источник правды о том, какие серверы ставит набор.
Всё, чего в нём нет, — не наше; снести это можно только вместе с чужим. Если каталог недоступен,
шаг говорит «отказ» и не трогает конфиги: угадывать «наше» он не станет.

## Что отложено осознанно

- **dry-run.** В аудите он назван «написанным для красоты». Конкретного места не нашли: все обещанные
  режимы плана (`center fresh` без `--yes`, `update --dry-run`, `clean-all` без `--yes`, `-WhatIf`)
  проверены тестами, а боевой вход дистрибутива режима плана и не обещает. Не чиним.
- **граф зависимостей.** Установщик не ставит python/venv под `camoufox-research` и прочие внешние
  окружения: предпосылки проверяет `center prereqs`, а неготовый сервер честно падает при обращении
  («окружение не найдено» — так и написано в его записи каталога). Понадобится раздача на голые машины —
  это придётся добавить; для своей сборки хватает предпосылок и честных отказов.

## Проверка

    bats tests/station.bats                    # снос: «снимает наши ссылки, чужое оставляет», «MCP по каталогу»
    node bin/cleanup.mjs plan                  # в плане — строка «чужое не снимается»

Установщики дистрибутива генерирует `dist/build.sh` (страница `install.sh` / `install.ps1` в архиве):
их режимы и README архива описаны там же, рядом с инструкцией «Обновление — новым архивом».
