# docs — документация системы

Как читать: это краткая карта, детали — в README каждого проекта (`../skills-hub/README.md` и т.п.).
Машинам тоже есть что взять: `center docs` печатает индекс и содержимое, `center docs --json <тема>` — путь к файлу (флаг назван `--json` исторически: он даёт машинный вид).

| тема | о чём |
|---|---|
| [00-map](00-map.md) | карта диска: что где лежит и кто с кем связан |
| [01-install](01-install.md) | установка с нуля на новой машине (и что остаётся руками) |
| [02-cleanup](02-cleanup.md) | снос агентов, скиллов, прошивок и MCP; подготовка к чистой установке |
| [03-agents](03-agents.md) | клиенты: omp, pi, opencode2 — конфиги и что ими управляет |
| [04-skills](04-skills.md) | скиллы: хаб, станция, слои, кастомные против сторонних |
| [05-mcp](05-mcp.md) | MCP: каталог серверов, ключи, пул с переключением |
| [06-prompts](06-prompts.md) | персоны и /prompt: база файлом и смена на ходу |
| [07-verify](07-verify.md) | проверки: doctor, живая проверка MCP (`verify`), check, наборы тестов, часовая автопроверка |
| [08-troubleshooting](08-troubleshooting.md) | грабли и лечение |
| [09-release](09-release.md) | версия набора, обновление проектов (`outdated`/`update`) и ритуал релиза |
| [10-plugins](10-plugins.md) | слэш-команда `/center` в клиентах (opencode2, omp, pi): установка, команды, сводка на старте |
| [11-zero-assumption](11-zero-assumption.md) | дисциплина набора: тринадцать правил против слепых допущений, зависаний, тяжёлых обходов и пустого исполнения; чем каждое держится |

Правило этих доков: только то, что проверено на этой машине; спорное помечено `[INFERENCE]`.
Числа и списки в них сверяет `../bin/docs-check.sh` (зовётся из `center check`): расходится док с кодом —
падает строка «сказано N, на деле M». Числа берут из кода и реестра, доки под них подгонять не нужно.
