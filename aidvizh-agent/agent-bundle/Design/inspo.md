# inspo — архив реальных сайтов как дизайн-референсы

## Источник

- Сервис и галерея: https://inspomcp.dev (можно смотреть руками, поиск по экранам).
- Репозиторий: github.com/Nutlope/inspo (MIT, открытый исходный код).
- Пакет: npm `inspo-mcp`, актуальная версия 0.1.16 (сентябрь 2026), является MCP-сервером (`mcpName: io.github.Nutlope/inspo`).
- Ядро архива: 832 реальных продакшен-сайта, 2320 экранов (десктоп + мобилка), 68 эталонных компонентов, DESIGN.md на каждый сайт (палитра, шрифты, type ramp, spacing, CSS-переменные).

## Установка

Локальный MCP (stdio) в `~/.config/opencode/opencode.json`, секция `mcp.servers`:

```json
"inspo": {
  "type": "local",
  "command": ["npx", "-y", "inspo-mcp"]
}
```

Альтернативы:

- Хостовый HTTP-эндпоинт без авторизации: `https://inspomcp.dev/api/mcp` (remote MCP, если локальный npx недоступен).
- Для других клиентов (Claude Code, Cursor, Codex, VS Code, Windsurf, Zed, Claude Desktop): `npx -y inspo-mcp install` сам найдёт клиента и впишет конфиг; `--dry-run` покажет план без записи.

## Ключи

Не нужны, архив открытый. Опционально:

- `TOGETHER_API_KEY` — включает векторное ранжирование в `search_screens` (без него поиск чисто лексический).
- `INSPO_PROFILE=lite` — оставляет 8 самых полезных тулов вместо 15 (экономит контекст).

## Что даёт

15 тулов, начинать с `recommend(brief)` — один вызов собирает moodboard: макроструктуру, 5 примеров, подходящие референс-компоненты, палитру и guidance по герою и отступам. Дальше `search_screens` для точечного поиска, `get_design_system(slug)` за DESIGN.md, `find_similar` / `find_by_color` / `find_examples_for_macrostructure` / `find_components` для добора, `get_reference_jsx(type, id)` за готовым JSX. `get_filters()` без аргументов отдаёт все валидные значения фильтров.

Фильтры: стиль, индустрия, 19 макроструктур (Bento Grid, Specimen, Manifesto и т.д.), режим, вайб, цвет, тип страницы, устройство, шрифтовой класс.

## Скиллы

Скиллов нет. Только MCP.

## Проверка

```bash
npx -y inspo-mcp
```

В opencode — вызовом тула `inspo.get_filters` (нулевой ввод, сразу видно, что каталог отвечает).

## Грабли

- Локальный stdio тянет каталог с CDN при старте — без сети сервер не поднимется, тогда переключаться на хостовый эндпоинт.
- У сервера свой бюджет вызовов: один `recommend`, одна-две `search_screens`, потом `get_screen` по трём-пяти финалистам. Больше — жрёт контекст впустую.
- Не звать, если в проекте уже есть своя дизайн-система, токены или устоявшийся паттерн — конвенции проекта важнее.
- Скриншоты отдаются абсолютными Vercel Blob URL, картинки компонентов — от `INSPO_BASE_URL` (по умолчанию inspomcp.dev).
