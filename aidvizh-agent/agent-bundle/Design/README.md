# Design — дизайн-референсы для агента

Зачем секция: агенту нужен вкус до того, как он пишет UI. Здесь лежат MCP-провайдеры, которые дают реальные продакшен-сайты, палитры, шрифты, сетки, компоненты и готовый DESIGN.md вместо фантазий из головы.

## Провайдеры

| Провайдер | Источник | Установка | Ключ |
|---|---|---|---|
| inspo | npm `inspo-mcp` (github.com/Nutlope/inspo, MIT) | сниппет local MCP в `inspo.md` (или `npx -y inspo-mcp install` для других клиентов) | не нужен |
| lazyweb | lazyweb.com (хостовый MCP, скилл-пак опционально) | сниппет remote MCP в `lazyweb.md` | Bearer-токен из бесплатного `install-token` (без логина) |

Детали и проверка — в `inspo.md`.

## Как добавить провайдера

1. Поставить MCP по доке провайдера (сниппет в `~/.config/opencode/opencode.json`, секция `mcp.servers`).
2. Новый файл `<провайдер>.md` по шаблону: Источник, Установка, Ключи, Что даёт, Скиллы, Проверка, Грабли.
3. Строка в таблицу выше.

Правило бандла то же: без секретов, только плейсхолдеры; вместо копий — источник + команда.
