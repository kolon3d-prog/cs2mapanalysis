# shadcn-admin — готовый шаблон админ-панели (React + Vite + Shadcn)

Оригинальный пост:

shadcn-admin - это готовый шаблон панели управления (Admin Dashboard), построенный на базе популярной библиотеки компонентов Shadcn UI с использованием технологий React и Vite.

Вместо того чтобы собирать интерфейс админки с нуля, разработчики могут использовать этот проект как готовую визуальную основу. Автор создал и структурировал коллекцию типовых страниц и кастомных компонентов, которые обычно требуются в корпоративных панелях и личных кабинетах.

Ключевые возможности
• Готовый интерфейс: содержит более 10 настроенных страниц (профили, списки, аналитика) и встроенный компонент боковой панели (Sidebar).

• Глобальный поиск: внутри есть удобное поисковое окно для быстрого переключения между разделами как в Spotlight или Raycast.

• Адаптивный дизайн: все таблицы, графики и кнопки автоматически подстраиваются под экраны смартфонов и планшетов.

• Поддержка RTL: часть стандартных компонентов Shadcn была модифицирована для корректного отображения языков с написанием справа налево (например, арабского).

• Темная и светлая темы: встроенное переключение оформления интерфейса из коробки.

Технический стек
• Интерфейс: Shadcn UI (под капотом TailwindCSS для стилей и Radix UI для логики элементов).
• Переходы между страницами: TanStack Router (современное решение для строгого управление маршрутами в React).
• Иконки: Lucide Icons и Tabler Icons.
• Основа проекта: Vite и TypeScript.
