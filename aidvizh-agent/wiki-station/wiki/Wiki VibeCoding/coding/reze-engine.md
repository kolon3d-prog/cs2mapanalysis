# reze-engine — WebGPU-движок MMD-анимации в браузере на TypeScript

Оригинальный пост:

Этот проект представляет собой движок трехмерного рендеринга на базе WebGPU, написанный на языке TypeScript.

Он создан специально для рендеринг в реальном времени (живой показ 3D-модели на экране), анимации и симуляции физики аниме-персонажей формата MMD (MikuMikuDance) прямо в браузере.

Главные особенности проекта
• Полная автономность: в движке нет сторонних зависимостей (zero dependencies), авторы написали собственную математическую библиотеку и собственный физический движок с нуля.
• Использование WebGPU: это современный стандарт графики для веба, который работает значительно быстрее устаревшего WebGL.
• Полноценная физика: симуляция твердых тел (сферы, капсулы, кубы) и пружинных соединений для реалистичного движения волос и одежды персонажей на частоте 60 Гц.
• Аниме-стилизация: система материалов поддерживает сел-шейдинг (эффект рисованного мультфильма), контуры и специальные шейдеры для глаз, кожи и волос.
• Работа с форматами MMD: движок умеет загружать трехмерные модели формата .pmx и файлы анимации движения .vmd.
• Дополнительные инструменты: поддержка блендинга анимаций (плавные переходы), управление персонажем с клавиатуры (WASD), создание скриншотов высокого разрешения и экспорт готового видео.
