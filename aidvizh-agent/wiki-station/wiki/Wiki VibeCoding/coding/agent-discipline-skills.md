# Набор скиллов «ИИ по правилам инженерии» (201K звёзд): /grill-me, /tdd и др.

Оригинальный пост:

У проекта 201.000 звезд.
Главная идея проекта - заставить искусственный интеллект работать по строгим правилам классической инженерии, а не просто генерировать код «по наитию».

Зачем нужен этот проект
Автор создал эти инструменты, чтобы решить главные проблемы при работе ИИ с кодом:
• Непонимание задачи: ИИ часто пишет не то, что от него ждали. Скилы заставляют его сначала детально допросить программиста.
• Многословие: ИИ тратит слишком много токенов на лишние рассуждения. Набор учит его использовать лаконичный, общий язык проекта.
• Неработающий код: Скилы внедряют строгую практику разработки через тестирование (TDD).
• Ухудшение архитектуры: Бесконтрольное написание кода агентом, превращает проект в хаос. Инструменты помогают поддерживать чистоту структуры.

Ключевые команды, которые добавляются ИИ:
/grill-me и /grill-with-docs - ИИ устраивает пользователю «допрос», чтобы до мельчайших деталей понять задачу до того, как начнет писать код.
/tdd - заставляет ИИ работать по циклу «тест → код → рефакторинг», то есть сначала писать падающий тест, а затем исправлять его.
/diagnosing-bugs - пошаговый цикл для отладки сложных багов (воспроизведение, гипотеза, проверка, исправление).
/improve-codebase-architecture - сканирует весь ваш код на наличие архитектурных проблем и выдает визуальный отчет.
/to-tickets - автоматически разбивает большую задачу или обсуждение на понятные и независимые задачи (тикеты).
