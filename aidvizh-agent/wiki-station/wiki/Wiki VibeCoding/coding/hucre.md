# hucre — сверхлёгкий кросс-платформенный движок таблиц на TypeScript

Оригинальный пост:

hucre - это сверхлегкий, быстрый и полностью автономный движок для работы с электронными таблицами, написанный на чистом TypeScript.

Главная идея проекта - дать разработчикам возможность читать и записывать файлы таблиц в любой среде без необходимости подтягивать тяжелые сторонние зависимости.

Какие проблемы он решает?
1. Работает абсолютно везде (Cross-platform): В отличие от старых библиотек, завязанных на Node.js, hucre не использует системные модули (вроде fs или crypto). Он одинаково стабильно работает на бэкенде (Node.js, Deno, Bun), в браузерах, в Web Workers и на Edge-платформах (Cloudflare Workers, Vercel Edge).

2. Нулевой вес для фронтенда: Традиционные библиотеки весят по 300–500 КБ. hucre полностью разделен на модули. Если вам нужно просто распарсить CSV, вы импортируете только этот кусок, и он займет всего 2.3 КБ в бандле. Сборка со всеми функциями (XLSX, ODS) весит около 114 КБ.

3. Безопасность для Enterprise: Библиотека на 100% совместима с политикой CSP (Content Security Policy), так как внутри не используются опасные конструкции вроде eval().

4. Экономия памяти при гигантских объемах: Позволяет обрабатывать многогигабайтные файлы построчно. Вы можете стримить данные из базы напрямую в скачиваемый пользователем XLSX-файл, не забивая оперативную память сервера.

Основные фишки и возможности
• Мультиформатность: Из коробки поддерживает чтение и запись XLSX, ODS, CSV, а также импорт/экспорт в JSON, NDJSON, XML и HTML-таблицы. Плюс умеет читать старые бинарные форматы XLS (97-2003) и XLSB.

• Сохранение структуры при редактировании: Если открыть существующий сложный Excel-файл (с макросами, графиками и Pivot-таблицами), изменить в нем одну ячейку и сохранить через метод openXlsx / saveXlsx, библиотека не сломает и сохранит все элементы, которые она сама даже не умеет обрабатывать.

• Первая JS-реализация нативных чекбоксов Excel 2024: Поддерживает новые встроенные флажки Microsoft на уровне движка. До этого такое умели делать только библиотеки на Python и Rust.

• Встроенный аудит доступности (WCAG 2.1 AA): Утилита умеет проверять созданные таблицы на доступность для скринридеров (проверяет наличие альтернативного текста у картинок, контрастность цветов ячеек, пропущенные заголовки и пустые строки).

• Продвинутые функции Excel: Поддерживает автоподбор ширины колонок (с учетом шрифтов и иероглифов), валидацию данных (выпадающие списки в ячейках), условное форматирование (13 типов правил) и защиту файлов паролем.

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: табличный движок на чистом TypeScript без системных модулей (работает везде: Node/Deno/Bun/браузер/Web Workers/Edge).
- Вес: CSV-парсер 2.3 КБ, полная сборка (XLSX/ODS) ~114 КБ (против 300–500 КБ у традиционных).
- Безопасность: CSP-safe (без eval()); стриминг многогигабайтных файлов построчно.
- Форматы: XLSX/ODS/CSV, JSON/NDJSON/XML/HTML, чтение XLS и XLSB; сохранение нетронутых элементов (макросы, графики, Pivot) при точечном редактировании (openXlsx/saveXlsx); чекбоксы Excel 2024 (первая JS-реализация); WCAG 2.1 AA аудит; автоподбор ширины (с учётом иероглифов), валидация, условное форматирование (13 правил), пароль.

Инженерно сильная библиотека: модульность (2.3 КБ за нужную фичу), CSP-safe, стриминг и «не сломай чужое» (сохранение структуры файла при точечной правке — как микро-патчи HermesOffice). Для наших веб-инструментов, которым нужны таблицы, — достойный кандидат против тяжёлых аналогов.
