# neonize — Python-библиотека WhatsApp на базе Whatsmeow

Оригинальный пост (ключевые части):

Мощная библиотека Python, созданная на базе Whatsmeow - обеспечивает бесшовную автоматизацию WhatsApp с производительностью корпоративного уровня.

🌟 Возможности
Базовый обмен сообщениями
✅ Отправка и получение текстовых сообщений
✅ Работа с медиафайлами (изображения, видео, документы, аудио)
✅ Управление группами и операции с ними
✅ События сообщений в режиме реального времени
✅ Квитанции о доставке/прочтении и отслеживание статуса сообщений

Продвинутые возможности
🔐 Поддержка сквозного (end-to-end) шифрования
🎯 Получение информации о контактах и пользователях
📞 Обработка событий звонков
🔔 Индикаторы присутствия и ввода текста
📊 Опросы и интерактивные сообщения
🚫 Управление черным списком

Удобство для разработчиков
🔄 Событийно-ориентированная архитектура
📊 Встроенное логирование и отладка
🗄 Поддержка баз данных SQLite и PostgreSQL
⚡️ Как синхронный, так и асинхронный API
🧪 Подробные примеры и документация

Библиотечный уровень автоматизации WhatsApp (ср. OpenWA — API-сервер): для встраивания в Python-пайплайны (боты, агенты). e2e-шифрование — нативная поддержка. Тот же нюанс ToS (неофициальные протоколы). Для наших скриптов-ботов — кандидат.
