# mapcn — красивые карты для сайта на MapLibre GL

Оригинальный пост:

Легко создавайте красивые карты для вашего сайта или приложения. Бесплатно, без настройки и одной командой

Ключевые особенности
• Быстрый старт: настройка одной командой без сложной конфигурации.
• Совместимость с shadcn/ui: используются те же подходы и правила стилизации.
• Стилизация через Tailwind CSS: позволяет легко адаптировать внешний вид компонентов.
• Поддержка тем: компоненты автоматически подстраиваются под светлую и темную темы приложения.
• База MapLibre GL: библиотека построена на движке MapLibre GL, обеспечивая высокую производительность работы с картами.

Функционал «из коробки»
• Маркеры и всплывающие окна: создание кастомных маркеров, подсказок и ярлыков.
• Элементы управления: встроенные кнопки масштабирования, компаса, геолокации и полноэкранного режима
• Отображение маршрутов: возможность рисовать пути и треки прямо на карте.

## Вывод

Для веб-проектов с картами — лёгкая альтернатива тяжёлым Leaflet/Mapbox-обвязкам, при этом в знакомом shadcn-стиле (ср. shadcn-admin, TailAdmin — экосистема дизайн-стандартов). Связано: GeoLibre (гео-инструменты). Пригодится для локаций/треков в наших проектах.
