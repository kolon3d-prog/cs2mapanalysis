# WrenAI — движок генеративной бизнес-аналитики для ИИ-агентов

Оригинальный пост:

WrenAI представляет собой движок генеративной бизнес аналитики, разработанный для ИИ агентов.

Он добавляет между агентом и базой данных, контекстный и семантический слой, в котором описываются бизнес показатели, модели, связи, правила доступа и проверенные примеры запросов.

Благодаря этому, агент может точнее интерпретировать вопросы на обычном языке, формировать проверяемый SQL и создавать аналитические панели.

Основные возможности:

• Поддержка более 22 источников данных, включая: PostgreSQL, ClickHouse, Snowflake, BigQuery, MySQL, DuckDB, Redshift и Databricks

• Семантическая модель MDL с бизнес определениями, вычисляемыми полями, связями и правилами доступа

• Предварительное планирование и проверка SQL перед выполнением

• Локальная память проверенных вопросов и запросов

• Создание интерактивных панелей и публикация через Vercel или Cloudflare Pages

• Интеграция с Claude Code, Cursor, Codex и другими агентами через навыки, SDK и MCP

• Возможность самостоятельного развёртывания и хранения бизнес контекста в обычных файлах с версионированием через Git

WrenAI снижает риск неправильной интерпретации данных, но не гарантирует абсолютную точность. Для надёжной работы необходимо правильно описать бизнес модель, настроить подключения, определить правила доступа и проверять сформированные запросы и показатели.
