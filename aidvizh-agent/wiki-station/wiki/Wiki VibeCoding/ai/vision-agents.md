# Vision Agents — ИИ-агенты, которые смотрят, слушают и понимают видео в реальном времени

Оригинальный пост:

Vision Agents - создание агентов, которые смотрят, слушают и понимают видео.

Разработан с прицелом на минимальную задержку.

Vision Agents позволяет создавать ИИ для работы с видео в реальном времени, совместимый с вашими моделями и периферийным уровнем.

Поддерживает YOLO, Moondream, Cartesia, Deepgram, ElevenLabs, HeyGen, Gemini, OpenAI и многие другие решения.

Быстрое переключение моделей. Простой в использовании API. Идеально подходит для инструментов коучинга, приложений для совместной работы, цифровых аватаров и робототехники.
