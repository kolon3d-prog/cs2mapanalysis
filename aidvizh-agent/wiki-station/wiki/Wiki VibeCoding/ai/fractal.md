# Fractal — иерархические агентские циклы с рекурсивной самоорганизацией

Оригинальный пост:

✦ Fractal — иерархические агентные циклы с рекурсивной самоорганизацией ✦

✅ Fractal превращает автономные агентные луп'ы в дерево: узел итерирует к цели в своём git worktree и порождает дочерние узлы для отделяемых подзадач — дерево растёт под задачу, а не по жёсткому плану.
🌳 Что внутри:

● Дерево git worktree'ов, каждый со своим автономным агентным циклом

● Жёсткие лимиты (итерации, глубина, дети, стоимость, время) держат каждый луп под контролем

● Оператор может управлять или остановить луп в любой момент

● Метаданные запуска (включая стоимость) — в локальной SQLite базе, с live-просмотром через TUI в терминале

🤖 5 агентных бэкендов "из коробки":
· Claude Code ·
· Codex ·
· Grok Build ·
· OpenCode ·
· Oh My Pi ·

✅ Роутинг через OpenRouter для Claude и Codex

⚙️ Установка:
pip install plasma-fractal
Плюс скилл /fractal [directive] — принимает инструкцию на естественном языке, сам достраивает параметры узла и запускает его в tmux-сессии.
