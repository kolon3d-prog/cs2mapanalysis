# Khoj — «второй мозг»: персональные и корпоративные ИИ-агенты

Оригинальный пост:

Khoj представляет собой платформу для создания персональных и корпоративных ИИ агентов, которые могут работать с документами, заметками, подключёнными источниками и информацией из интернета.

Проект позиционируется как «второй мозг»: пользователь может задавать вопросы по своим материалам, искать нужные сведения обычным языком, выполнять семантический поиск по собственной базе знаний, создавать специализированных агентов и автоматизировать повторяющиеся задачи.

Khoj можно использовать через облачный сервис разработчиков или развернуть самостоятельно на своём компьютере либо сервере.

Основные возможности

1. Общение с собственными документами
Khoj индексирует подключённые материалы и позволяет задавать вопросы по их содержимому в формате обычного диалога.

Платформа поддерживает:
• PDF документы
• файлы Microsoft Word
• Markdown
• обычные текстовые файлы
• заметки Org mode
• страницы Notion
• репозитории GitHub
• изображения и другие поддерживаемые источники

2. Семантический поиск
Вместо точного совпадения слов, Khoj использует семантический поиск и пытается определить смысл запроса.

Например, документ не обязательно должен содержать формулировку «условия возврата средств». Система может найти раздел, в котором эта информация описана другими словами.

При самостоятельном развёртывании, индексация и поиск по личным данным выполняются в собственной инфраструктуре пользователя. Поддерживается постепенное обновление индекса при добавлении и изменении документов.

3. Работа с разными языковыми моделями

Платформа может работать с локальными и облачными моделями, включая семейства:

• Llama
• Qwen
• Gemma
• Mistral
• GPT
• Claude
• Gemini
• DeepSeek

4. Пользовательские ИИ агенты
В Khoj можно создавать специализированных агентов с собственной ролью, инструкциями, знаниями, языковой моделью и доступными инструментами.

Например, можно создать:

• помощника для анализа внутренней документации
• исследовательского агента
• редактора текстов
• консультанта по определённому проекту
• агента для подготовки отчётов
• помощника по работе с технической базой знаний

Для каждого агента можно задать собственную системную инструкцию и определить, будет ли он доступен всем пользователям сервера или только конкретному владельцу.

5. Поиск информации в интернете
Помимо личных документов, Khoj может использовать интернет для получения актуальной информации.

Это позволяет объединять внутренние знания пользователя с внешними источниками. Например, система может сопоставить данные из проектной документации с текущими сведениями из открытых источников.

6. Автоматизация исследований
Khoj позволяет создавать повторяющиеся задания, которые выполняются по расписанию.

Платформа может:
• регулярно исследовать заданную тему
• следить за обновлениями
• готовить персональные информационные подборки
• формировать новости по интересующим направлениям
• отправлять уведомления и результаты по электронной почте

Такие автоматизации подходят для мониторинга отраслевых новостей, конкурентов, научных публикаций, технологий и других постоянно меняющихся тем.

7. Генерация изображений и голосовое взаимодействие
Khoj поддерживает генерацию изображений, голосовые сообщения, распознавание речи и озвучивание ответов.

Благодаря этому с помощником можно взаимодействовать не только через текстовый чат, но и голосом.

8. Выполнение кода
В платформе предусмотрены функции выполнения кода, которые могут использоваться для вычислений, анализа данных и решения задач, требующих программной обработки.

Доступность и безопасность этой функции зависят от конфигурации конкретного сервера и подключённых инструментов.

С Khoj можно работать через разные приложения и среды:

• веб интерфейс
• десктопное приложение
• расширение для Obsidian
• пакет для Emacs
• мобильное устройство
• WhatsApp

Это позволяет использовать одну базу знаний из привычной рабочей среды, не ограничиваясь отдельным сайтом.
