# UEmbed — мультимодальные эмбеддинги от Alibaba (2B/4B/9B)

Оригинальный пост:

UEmbed (https://alibaba-nlp.github.io/UEmbed/)
мультимодальная модель эмбеддингов от Alibaba
2B, 4B, 9B

UEmbed это decoder‑only модель, которая в одном проходе генерирует сразу два типа представлений:

- плотные (dense) для семантического поиска и задач типа retrieval
- разреженные (sparse, лексические) хорошо работает для классического лексического поиска

При этом модель принимает на вход текст, изображения и видео и выдаёт для них совместимые эмбеддинги, то есть можно искать текст по картинке, картинку по видеофрагменту и т. п.

Единое векторное пространство: разные модальности приводятся к общему представлению, что удобно для гибридного поиска.

## Контекст

- Пост готовый, ссылки не проверялись (по указанию автора).
- Что: мультимодальная модель эмбеддингов (размеры 2B/4B/9B): decoder-only, один проход → два типа представлений (dense для семантики + sparse для лексики).
- Вход: текст, изображения, видео → совместимые эмбеддинги в едином векторном пространстве (кросс-модальный поиск: текст по картинке, картинка по видео).
- Назначение: гибридный поиск (семантика + лексика).

## Вывод

Для поисковых задач (наш research.db, Wiki) такие модели — путь к семантическому поиску по всем модальностям сразу. Интересно: один проход даёт и dense, и sparse — не нужно держать две модели. Если понадобится улучшить поиск по базе (сейчас FTS) — UEmbed 2B кандидат на замер (spike → ADR по нашему правилу).
