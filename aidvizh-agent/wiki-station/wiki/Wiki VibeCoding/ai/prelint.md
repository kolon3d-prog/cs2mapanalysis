# Prelint — продуктовая проверка для кода, написанного ИИ

Оригинальный пост:

🧭 Prelint — продуктовая проверка для кода, написанного ИИ.

Обычный code review отвечает на вопрос «работает ли код?». Prelint проверяет другое: соответствует ли pull request спецификациям, бизнес-правилам, архитектурным решениям и ограничениям продукта. Сервис читает документацию проекта и оставляет замечания прямо в GitHub/GitLab, если агент начал строить «не то».

Полезно командам, где Claude Code, Cursor и другие агенты уже пишут заметную часть кода.

ИЗ-ЗА: границы.

Сайт: https://prelint.com

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Позиционирование: «продуктовый lint» — проверка не корректности кода, а соответствия намерениям продукта (спеки, бизнес-правила, архитектура, ограничения).
- Как работает (по посту): читает документацию проекта, сравнивает PR с ней, оставляет замечания в GitHub/GitLab.
- Целевая аудитория: команды, где значительную часть кода пишут ИИ-агенты (Claude Code, Cursor и т.п.).

## Вывод

Prelint закрывает реальную проблему agentic-разработки: агенты пишут рабочий код, который может не соответствовать продукту («построил не то»). Отдельный слой проверки «код против спеки» — логичное дополнение к классическому code review. Стоит иметь в виду как паттерн: ревью по контракту продукта, а не по компиляции.
