# Greplica — общая самообновляющаяся память кодовой базы для агентов

Оригинальный пост:

Greplica — общая, самообновляющаяся память кодовой базы для AI-агентов и команды 🧠🔀

📚 Постоянно вытаскивает из сессий кодинг-агентов решения, ограничения, грабли, неудачные подходы и file-level контекст — и отдаёт агенту только то, что реально нужно под текущую задачу, а не весь дамп.

🔍 Явно бьёт как по грепу (Claude — «мастер грепа», медленно на больших базах), так и по семантическому поиску (у Cursor он «failure prone») — заявлено 50% экономии токенов и 30% времени на планирование в собственных бенчмарках авторов.

🔌 Два режима: Local — полностью локально, без телеметрии и облака; Managed — общая память репозитория для контрибьюторов на разных клонах и форках, с ролями admin/member/contributor/guest.

⚙️ Установка через один промпт агенту прямо из репозитория:

npm install -g greplica

📊 Есть граф-визуализация памяти (компоненты, потоки, claims, источники, связи) — self-contained HTML-экспорт, работает офлайн.
