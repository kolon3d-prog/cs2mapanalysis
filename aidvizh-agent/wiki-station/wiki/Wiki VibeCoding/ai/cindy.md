# Cindy — мульти-harness агент: Claude Code и Codex в одной системе

Оригинальный пост:

Cindy — открытый AI-агент, готовый к работе с первого запуска 🤖🐈‍⬛

Устал держать отдельные окружения под Claude Code и Codex, теряя память и контекст при переключении? Cindy это чинит.

🧩 Мульти-harness архитектура: Claude Code и Codex работают внутри одной Cindy, харнесс или модель можно переключить прямо посреди задачи — воркспейс, память, скиллы и тулы не сбрасываются.

👥 Multi-agent режим: одна модель планирует (Claude Code × Fable 5), несколько воркеров параллельно исполняют (Codex/Claude Code × Grok, Kimi, GLM), отдельная модель ревьюит диф (Codex × GPT-5.6) — Cindy держит контекст и acceptance criteria на всех этапах.

🔒 Контроль на стороне пользователя: изменения идут в изолированный воркспейс, каждый диф проходит построчное ревью, есть откат к чекпоинту, а необратимые решения агент без спроса не принимает.

🌍 Работает и без вас: делегирование из Slack/Feishu, управление с телефона, задачи по расписанию — Cindy сама всё запускает и репортит в чат.

🔌 Открыта для расширения: 20+ встроенных тулов, MCP, свои скиллы и плагины; можно подключить свой API-ключ, существующий Coding Plan или локальные модели через Ollama/vLLM.

💰 Софт бесплатный — платите только за модели (свой ключ / готовая подписка / managed-сервис Cindy от $20/мес).

🔓 Apache-2.0, open source
🔗 GitHub: github.com/makecindy/cindy
🌐 Сайт: cindy.app
