# GenericAgent — минималистичный агент, который растит дерево навыков

Оригинальный пост:

GenericAgent — минималистичный агент, который сам растит своё дерево навыков, а не тащит их заранее 🌱🤖

🧬 Ядро — всего ~3K строк кода: 9 атомарных тулов + агент-цикл на ~100 строк дают любой LLM системный контроль над локальным компьютером — браузер, терминал, файловая система, клавиатура/мышь, зрение, мобильные устройства через ADB.

🌳 Философия «не предзагружай навыки — выращивай их»: каждую решённую задачу агент кристаллизует в переиспользуемый Skill — чем дольше пользуешься, тем больше личное дерево навыков.

🤯 Весь этот репозиторий сам себе и написал — от установки Git до каждого коммита, автор ни разу не открывал терминал.

💬 Фронтенды: десктоп-приложение, TUI, плюс Telegram, Discord, Lark, WeChat, QQ, WeCom, DingTalk.

🔌 OpenAI-совместимый и Anthropic native API — GPT, Claude, Kimi, MiniMax, DeepSeek, GLM, Qwen, Gemini.

💻 Требования: Windows 10/11, macOS 12+ или Linux; Python 3.11/3.12 (3.14 не подходит); на macOS сборка не нотаризована — карантин снимать вручную.

⚠️ Риск установки:
Заявленная функция — полный системный контроль над локальной машиной: терминал, файлы, ввод, скриншоты, подключённые телефоны. Любая ошибка планирования исполняется на реальном рабочем столе, а не в песочнице. Плюс механизм самоэволюции: набор умений меняется сам со временем, и то, что было безопасно вчера, сегодня может повести себя иначе. Ставить такое стоит в виртуалку или на отдельную машину — не на рабочий ноутбук с ключами и почтой.

⚠️ Установочные скрипты по умолчанию на китайском, часть бинарников качается со стороннего домена автора, а не из GitHub Releases — сверяйтесь с официальным README.
