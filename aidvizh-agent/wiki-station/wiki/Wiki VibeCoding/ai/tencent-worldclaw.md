# Tencent WorldClaw — агентная генерация 3D-миров из промпта

Оригинальный пост:

Tencent показала WorldClaw — систему ИИ-агентов, которая по одному промпту собирает целые 3D-миры 🤩

Система сама планирует карту, генерирует ландшафт, материалы и объекты, расставляет всё по сцене и начинает этап проверки. В это время WorldClaw делает диагностические рендеры в Blender, ищет багнутые объекты неправильного масштаба или ориентации и чинит всё, доводя до идеала. Но, если захочется, объекты можно редактировать и вручную.

## Контекст (проверено по первоисточнику)

- **Кто:** Tencent Hunyuan3D Research (Chunchao Guo, Yang Li — project leads).
- **Что:** WorldClaw — fully agentic, coarse-to-fine фреймворк open-world 3D-генерации.
- **Как работает:** planning-агенты переводят текстовый промпт в структурированную спецификацию (регионы, террейн, ассеты, материалы, пространственные связи) → глобальная генерация террейна (семантические layout'ы, region-aware height field) → региональная генерация и размещение объектов → render-based агенты уточняют террейн, объекты, контакты.
- **Ключевое:** каждый объект остаётся отдельным редактируемым экземпляром (instance-level editable assets), а не слитым мешем. Часть ассетов — процедурная генерация через 3D-кодинг, остальное — 3D-генеративные модели.
- **Демо:** 11 миров (снежная деревня, каньон, тропический остров, арктический форпост и др.), рендеры: RGB, instance-маски, нормали, depth.
- **Ссылки:** arXiv + GitHub на странице проекта.

## Вывод

WorldClaw — яркий пример перехода от «генерации одной 3D-модели» к «генерации целой сцены с редактируемыми ассетами» через оркестрацию специализированных агентов. Показателен паттерн «сгенерировал → отрендерил → проверил → починил» (diagnostic renders + fix loop). Для 3D-моделлеров это сигнал: рутина сборки сцены автоматизируется, но редактирование и контроль остаются за человеком.
