# AgentScope 2.0 — фреймворк агентных приложений с руководителем и исполнителями

Оригинальный пост:

Agent Scope 2.0 это фреймворк для создания и развёртывания ИИ агентов. Он предназначен не только для вызова языковой модели, но и для построения полноценных агентных приложений с инструментами, памятью, несколькими пользователями и серверной частью.

Основные возможности:

• совместная работа нескольких агентов с руководителем и специализированными исполнителями
• поддержка MCP и Skill Hub для подключения инструментов и навыков
• RAG, базы знаний и интеграции долговременной памяти через Mem0 и ReMe
• система разрешений для контроля команд, файловых операций и других инструментов
• многопользовательский и многосессионный сервис на базе FastAPI
• изолированные рабочие среды через Docker, E2B, Daytona, Kubernetes, OpenSandbox и другие backend реализации
• единый поток событий для веб интерфейсов, потоковых ответов, подтверждения действий и участия человека
• подключение разных моделей и провайдеров через единый агентный слой

В отличие от систем, построенных вокруг большого количества жёстко заданных workflow, AgentScope старается активнее использовать собственные возможности современных моделей: рассуждение, выбор инструментов, планирование и распределение задач между агентами.

При этом проект всё ещё активно развивается и имеет статус Beta. Многие функции требуют отдельных зависимостей и внешних сервисов, поэтому AgentScope правильнее считать серьёзной основой для агентных систем, а не полностью готовой производственной платформой, которую можно развернуть без дополнительной настройки.
