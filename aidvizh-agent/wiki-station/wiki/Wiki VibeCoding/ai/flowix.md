# Flowix — Markdown-заметки как долгосрочная память для нескольких агентов

Оригинальный пост:

Flowix - это приложение для заметок на базе Markdown. Оно превращает ваши требования, исследования, решения и контекст проекта в долгосрочную память, которую могут постоянно читать и обновлять несколько ИИ-агентов.

Поддерживает подключение таких инструментов, как Codex, Claude Code, OpenCode, Hermes и других, через MCP или CLI.

Главная проблема современных автономных ИИ-агентов (таких как Codex, Claude Code или Hermes) заключается в том, что они начинают каждую новую рабочую сессию «с чистого листа», из-за чего разработчику приходится заново объяснять контекст.

Flowix решает эту проблему за счет объединения заметок и памяти агента в один рабочий процесс:

• Локальный Markdown для полного контроля: ваши требования к коду, контекст проекта и промпты хранятся локально в структурированном виде в одном месте, а не разбросаны по разным чатам и файлам. Это устраняет хаос в инструкциях.

• Общий контекст для долгосрочной памяти: несколько разных внешних агентов используют один и тот же набор данных. Агент больше не совершает одни и те же ошибки, потому что он может постоянно обращаться к актуальной истории решений и проектным ограничениям.

• Прямая запись для сохранения результатов: ответы и выводы работы агентов записываются обратно в исходные заметки. Ценные выводы, сгенерированные блоки кода или результаты исследований из диалогов автоматически сохраняются в те же Markdown-файлы для повторного использования.

• Управление проектом через внешние инструменты: файлы остаются обычным текстом на вашем устройстве, что позволяет использовать любые привычные способы синхронизации, бэкапов и контроля версий через Git.
