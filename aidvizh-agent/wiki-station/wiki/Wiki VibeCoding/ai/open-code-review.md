# Open Code Review — Alibaba открыла свой AI-ревьюер кода

Оригинальный пост:

🚀 Alibaba открыла свой внутренний AI-инструмент для ревью кода — Open Code Review.

Это не просто очередной AI-ревьюер, а система, которая больше двух лет использовалась внутри Alibaba. За это время через неё прошли десятки тысяч разработчиков, а инструмент помог обнаружить миллионы дефектов в коде. Теперь проект стал open source.

Что умеет:
• анализирует Git Diff, а не только отдельные файлы;
• оставляет комментарии с привязкой к конкретным строкам;
• умеет читать весь проект и учитывать контекст изменений;
• ищет потенциальные NPE, проблемы с потоками, SQL-инъекции, XSS и другие типовые ошибки;
• работает с OpenAI, Anthropic и совместимыми API.

Главная идея проекта — не полагаться только на LLM. Alibaba совместила детерминированные алгоритмы (они гарантируют, что ни один важный файл не будет пропущен) + AI-агента, который уже проводит глубокий анализ кода. Такой гибридный подход делает ревью стабильнее, чем у обычных AI-агентов.

Если работаете с большими репозиториями или регулярно проверяете PR — проект точно стоит добавить в закладки.

🔗 GitHub: https://github.com/alibaba/open-code-review

## Вывод

Прямой аналог нашего CRG-подхода (детерминированный граф + LLM-анализ) и Prelint/Rejudge. «Не полагаться только на LLM» — подтверждение нашей философии: структура/алгоритмы как гарантия полноты, LLM как глубина. Для ревью PR — сильный кандидат на замер.
