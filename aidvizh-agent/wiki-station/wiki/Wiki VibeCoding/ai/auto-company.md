# Auto-Company — 14 ИИ-агентов, вдохновлённых великими экспертами

Оригинальный пост (ключевые части):

Auto-Company - проект, который координирует 14 ИИ-агентов, каждый из которых вдохновлён образом мышления конкретного эксперта.

В команду входят:
→ Джефф Безос в роли CEO
→ Вернер Фогельс в роли CTO
→ Чарли Мангер в роли критика
→ Дон Норман в продукте
→ DHH пишет код
→ Келси Хайтауэр управляет развёртыванием
→ Сет Годин занимается маркетингом
→ Пол Грэм в операционной деятельности
→ Аарон Росс в продажах

Это не просто имена, приклеенные к промпту.

Каждый агент получает:
• Конкретную роль
• Принципы принятия решений
• Чёткие обязанности
• Методы работы
• Собственные документы и папки
• Критерии для взаимодействия с остальной командой

Работа выстроена довольно дико:
1. Агенты исследуют возможности
2. Предлагают продукты
3. Чарли Мангер пытается уничтожить плохие идеи
4. CEO решает, что строить
5. Формируется команда из 3–5 агентов
6. Проектируют продукт
7. Пишут код
8. Выполняют тесты
9. Готовят развёртывание
10. Обновляют общую память
11. Засыпают

Начинают следующий цикл

Всё выполняется непрерывно прямо на вашем компьютере.

В качестве движка проект использует Claude Code или Codex CLI, поэтому агенты могут:
→ Читать и записывать файлы
→ Выполнять команды
→ Создавать репозитории
→ Делать коммиты
→ Искать в интернете
→ Строить приложения
→ Готовить кампании
→ Разворачивать проекты

Компания сохраняет контекст между циклами с помощью файла консенсуса, который выступает как единый источник истины; каждая команда оставляет запись о том:
• Что сделала
• Что решила
• Что провалилось
• Что должно произойти дальше

Благодаря этому следующий цикл может продолжаться, не начиная с нуля.

Также предусмотрены механизмы для:
→ Ожидания, когда API ограничивает запросы
→ Восстановления после последовательных ошибок
→ Отката циклов, не создавших валидный консенсус
→ Перезапуска после сбоев
→ Работы на Windows, macOS и Linux

Её миссия, находить реальный спрос, создавать ценные продукты и законно приносить доход.

Важно: это не значит, что вы сможете нажать кнопку и проснуться с доходной компанией.

Вам нужно настроить модель, разрешения, учётные данные и внешние сервисы. Предоставление автономного доступа к командам и развёртыванию также сопряжено с рисками.

- Движок: Claude Code/Codex CLI; честное предупреждение автора: не «кнопка → доходная компания», нужна настройка, есть риски автономного доступа.

## Вывод

Самая амбициозная «агентная компания» в нашей библиотеке (ср. MetaGPT, Mastra Factory): экспертные персоны + цикл + консенсус-память. Паттерн «Чарли Мангер уничтожает плохие идеи» — адвокат дьявола до дорогих решений (наш nodumb!). Консенсус-файл — наш research.db/прошивка правил. ⚠️ Риски автономного деплоя — автор честно предупреждает.
