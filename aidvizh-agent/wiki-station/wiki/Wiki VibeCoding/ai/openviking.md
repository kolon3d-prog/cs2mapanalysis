# OpenViking — контекст-база агентов как виртуальная файловая система

Оригинальный пост:

OpenViking представляет собой базу данных контекста, созданную специально для ИИ-агентов.

Она сохраняет воспоминания, ресурсы и навыки в виде единой виртуальной файловой системы, которая работает по протоколу viking://. Благодаря этому агент просматривает свой собственный контекст с помощью привычных команд вроде ls, tree и find вместо того, чтобы отправлять запросы в скрытую векторную базу данных.

Весь контент разделяется на три уровня, среди которых находятся L0 (абстрактное описание), L1 (общий обзор) и L2 (подробные детали), а затем загружается по мере необходимости. Каждое извлечение данных оставляет за собой четкий след, который вы можете изучать и отлаживать.

https://github.com/volcengine/OpenViking
