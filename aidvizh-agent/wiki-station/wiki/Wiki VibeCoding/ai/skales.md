# Skales — персональный AI-агент на компьютере: цель → результат

Оригинальный пост:

Skales — персональный AI-агент для компьютера: ставишь цель, он сам доводит её до конца 🦎🤖

📌 Что это: приложение, которое живёт на вашем компьютере и умеет само выполнять многошаговые задачи — заходить в файлы, браузер, календарь, почту — вместо того чтобы вы вручную кликали по каждому шагу.

🖥 Computer Use: агент видит экран (скриншот) и сам управляет мышью/клавиатурой — кликает, печатает, скроллит.

🌐 Встроенный браузер: сам ходит по сайтам, кликает по кнопкам, вытаскивает нужный контент.

👥 Teams — можно связать два устройства (агенты + люди) в одну команду, есть Agent2Agent-координация для мультиагентных «организаций».

📅 Планировщик с синком календаря (Google/Apple/Outlook), фоновые повторяющиеся задачи — можно поставить цель и закрыть ноутбук, агент сам напишет в WhatsApp/Telegram, когда закончит.

🔌 15+ AI-провайдеров (свой ключ), либо бесплатный встроенный триал Skales IQ без ключа вообще, либо полностью офлайн через Ollama.

🔄 Готовый импорт настроек при переезде с ChatGPT, Claude, Copilot, Gemini, OpenClaw, Hermes.

📱 Мобильный компаньон на Android/iOS — привязывается к десктопу по QR или работает отдельно.

⚠️ Стоит помнить: у агента есть реальный доступ к файлам, браузеру, почте и управлению экраном — прежде чем давать полный доступ, стоит проверить, какие права запрашиваются, особенно если на машине есть рабочие данные или сохранённые пароли.

📋 Системные требования:
— ОС: Windows, macOS (Apple Silicon и Intel), Linux — десктоп; Android/iOS — мобильный компаньон
— Установка: один клик, без Docker и терминала (~30 секунд)
— GPU не нужен (кроме локального запуска через Ollama — там требования зависят от выбранной модели)

🔓 Лицензия BSL 1.1 — бесплатно для личного/образовательного/некоммерческого использования, для коммерческого SaaS нужно отдельное разрешение (переходит в Apache 2.0 в апреле 2030); WordPress-плагин отдельно под MIT.

👤 Разработчик — Марио Симич (соло-фаундер, Вена)
