# Continuum — бесшовный переход между AI-агентами через реестр памяти

Оригинальный пост:

🛠 Continuum (https://github.com/AnasNafees1802/continuum): бесшовный переход между AI-агентами

Представлен open-source проект Continuum для обеспечения непрерывности сессий между различными AI-агентами программирования. Инструмент создает структурированный реестр памяти (.aicontext/) внутри проекта, позволяя агентам (таким как Claude Code, Cursor и др.) читать текущее состояние, задачи и принятые решения.

Решает проблему «силосов контекста», предлагая универсальный протокол передачи состояния, не привязанный к конкретному вендору. Это приближает разработку к стандартизации взаимодействия между автономными инструментами.

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: реестр памяти `.aicontext/` внутри проекта — структурированное состояние (текущие задачи, решения), которое читают разные агенты (Claude Code, Cursor и др.).
- Проблема, которую решает: «силосы контекста» — каждый агент/харнес хранит контекст по-своему и не видит работу других.
- Идея: универсальный, вендор-независимый протокол передачи состояния между автономными инструментами.
