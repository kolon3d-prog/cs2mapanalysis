# TencentDB Agent Memory — инфраструктура долгосрочной памяти для агентов

Оригинальный пост:

TencentDB Agent Memory представляет собой инфраструктуру долгосрочной памяти для ИИ агентов и агентных команд.

Она сохраняет разговоры, извлекает факты и сценарии, превращает успешные процессы в навыки, строит базу знаний по документам, анализирует структуру исходного кода и назначает эти материалы конкретным агентам с учётом прав доступа.

Главная идея проекта заключается не в том, чтобы хранить все разговоры подряд, а в том, чтобы определить, какая информация действительно пригодится снова, кто имеет право её использовать и как передать её нужному агенту в подходящий момент.

Проект не запускает агентный цикл и не является самостоятельным ИИ агентом. Он работает как инфраструктурный слой между агентом, языковой моделью, документами, кодовой базой и накопленной памятью.
