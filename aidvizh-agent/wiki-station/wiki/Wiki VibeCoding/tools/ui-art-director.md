# UI Art Director — набор скиллов дизайн-ревью для агентов (jakubkrehel)

Оригинальный пост:

ИИ-артдиректор для ваших интерфейсов — разраб собрал (https://github.com/jakubkrehel/skills) бесплатный набор скиллов, который проводит полноценное дизайн-ревью и убирает из продукта тот самый ИИ-вайб.

Сервис отдельно проверяет типографику, цвета, структуру, отступы, радиусы, тени, анимации, адаптивность, доступность и даже тексты на кнопках. Главный скилл better-interface управляет остальными шестью и сводит все замечания в единый отчёт с конкретными правками.

По сути, это готовый UX/UI-чек-лист с точными цифрами и принципами, который не нужно пытаться самостоятельно объяснить агенту 💃

## Дополнительный пост (повторный, тот же набор, третий раз в потоке)

Имба: пачка UI-скиллов для ИИ-агентов, которые делают интерфейс максимально удобным и комфортным.

Каждый навык улучшает дизайн, типографику и все элементы интерфейса:

• better-interface — улучшает общий стиль UI и оркестрирует все остальные скиллы.
• better-ui — делает UI более качественным и продуманным.
• better-typography — прокачивает типографику, шрифты и интервалы.
• better-colors — генерит цветовые палитры и темы оформления.
• better-accessibility — улучшает доступность интерфейса.
• better-layout — улучшает структуру макета, группирует и выравнивает элементы.
• better-writing — генерит тексты: от подписей на кнопках до сообщений об ошибках.

Работает в Claude Code, Codex и других ИИ-агентах.

Кодим с комфортом — тут (https://github.com/jakubkrehel/skills).
