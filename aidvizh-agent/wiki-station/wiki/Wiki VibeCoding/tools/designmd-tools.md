# Design.md-генераторы: refero, neuform, designmd, designmd supply, getdesign, расширение

Оригинальный пост:

Коллекция сайтов с инструментами для DESIGN.md:

1. refero (https://styles.refero.design/) - база из 2000+ файлов DESIGN.md, расширенный конфиг-вывод, поддержка конфигурации под Tailwind версии 4, CSS-переменные и токены дизайна.
2. neuform (https://neuform.ai/) - более сильная визуальная часть, удобнее для восприятия интерфейсов.
3. designmd (https://designmd.me/) - вставляешь URL — получаешь готовый DESIGN.md с токенами, типографикой и паттернами компонентов.
4. designmd supply (https://designmd.supply/) - тоже самое. Принимается любой публичный домен
5. getdesign md (https://getdesign.md/) - умеет принимать любой сайт и генерировать дизайн-спецификации и конфигурации.
6. design-md-chrome (https://github.com/bergside/design-md-chrome) - расширение Chrome для быстрого использования прямо в браузере.
