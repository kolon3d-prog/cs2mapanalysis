# CodexThemes — Wallpaper Engine для Codex: каталог тем

Оригинальный пост:

🎨 CodexThemes — Wallpaper Engine, только для Codex
Галерея кастомных тем для десктопного Codex от OpenAI. Аналогия с Wallpaper Engine рабочая, только меняется не картинка на фоне, а весь воркспейс: фоны, палитра, панели, акценты.
Что внутри:
→ Каталог тем и скинов с полными превью — показывают Home, Task, Diff и Composer до установки. Сразу видно, это читаемо или красиво-но-работать-невозможно
→ Фильтры по light / dark / настроению
→ Своя тема из одной референс-картинки или просто описания вайба — агент собирает сам
→ Ставится не руками: качаешь скилл, кидаешь промпт в Codex — он сам находит, устанавливает, применяет и проверяет результат
→ Свою тему можно опубликовать в общую галерею
Важный момент по безопасности: тема инжектится в сессию через локальный дебаг-порт, а не патчит подписанный бандл. app.asar и данные авторизации не трогаются, откат — одной командой. macOS и Windows, но сборки из сторов без Chromium-флагов не заведутся.
