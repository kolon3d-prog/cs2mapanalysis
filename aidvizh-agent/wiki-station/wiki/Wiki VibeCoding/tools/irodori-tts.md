# Irodori-TTS — японский синтез речи с эмоциями через эмодзи

Оригинальный пост:

Irodori-TTS - инструмент для синтеза речи (Text-to-Speech) с японским уклоном, разработанная независимым создателем под ником Chihiro Arata.

В основе её архитектуры лежит современный подход Flow Matching (разновидность диффузионных моделей). Модель умеет преобразовывать написанный текст в высококачественное аудио с частотой дискретизации 48 кГц.

Проект создан как гибкий инструмент для генерации естественной озвучки, клонирования голосов и кастомизации аудио.

• Клонирование голоса (Voice Cloning): модель способна скопировать голос реального человека по короткому аудио-примеру (от нескольких секунд) и озвучить им любой новый текст.
• Управление эмоциями через эмодзи: уникальная деталь проекта. Если вставить в текст для озвучки смайлики (например, 🤭 или 😮‍💨), нейросеть изменит интонацию, добавит смешок или вздох в этих местах.
• Дизайн голоса по текстовому описанию (VoiceDesign): вы можете буквально текстом прописать, какой голос вам нужен. Например: «Спокойный мужской голос, говорит уставшим, но тёплым тоном». Модель сама сгенерирует тембр и нужную эмоцию.
• Интеграция с ИИ-агентами: проект генерирует готовые системные промпты, что позволяет использовать озвучку в связке с умными терминалами разработки (вроде Claude Code или Codex) для создания полноценных голосовых ассистентов.

Кому это полезно
• Разработчикам голосовых ИИ-агентов: для интеграции качественной озвучки в свои приложения.
• Контент-мейкерам: для озвучивания видеороликов, подкастов или локализации контента на японский язык.
• Геймдев-разработчикам: для быстрой черновой (или даже чистовой) озвучки персонажей в инди-играх по текстовому описанию.

Проект имеет удобный веб-интерфейс на Gradio, поддерживает запуск в Google Colab и оптимизирован для работы на обычных пользовательских видеокартах. Код распространяется под свободной лицензией MIT.
