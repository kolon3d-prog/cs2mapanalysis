# Gmail Account Creator — автоматизация регистрации Gmail через браузер (серая зона)

Оригинальный пост:

Gmail Creator Pro представляет собой приложение для Windows, предназначенное для автоматизации регистрации учётных записей Gmail через браузер.

Программа управляет Google Chrome, заполняет регистрационные формы, подставляет имена, даты рождения и другие данные, а затем сохраняет сведения о созданных аккаунтах. Проект ориентирован в том числе на последовательное создание большого количества учётных записей.

Основные возможности
• Автоматизация регистрации
Приложение выполняет основные этапы создания аккаунта Gmail через браузер. Для управления Chrome используются Selenium и ChromeDriver.

В настройках можно указать пароль, список имён, дату рождения, пол и набор идентификаторов браузера. Данные вынесены в отдельные конфигурационные файлы.

• Имитация обычного поведения пользователя
По заявлению разработчика, программа добавляет случайные задержки при вводе текста, меняет идентификаторы браузера и выполняет дополнительные действия перед регистрацией.

Эти механизмы предназначены для уменьшения вероятности обнаружения автоматизации. Однако проверить их реальную эффективность невозможно, поскольку основной исходный код программы в репозитории отсутствует.

• Работа с подтверждением номера
Проект заявляет интеграцию с сервисом 5sim для получения временных телефонных номеров и кодов подтверждения по SMS.

Пользователь может указать API ключ, страну и оператора в конфигурации приложения. Также программа заявляет попытки продолжить регистрацию без номера телефона, когда интерфейс Google предоставляет такую возможность.

• Поддержка прокси
В описании проекта заявлена возможность выбора и проверки прокси серверов для изменения IP адреса между регистрациями.

В списке зависимостей присутствует библиотека FreeProxy, которая может использоваться для получения общедоступных прокси серверов.

• Консольный интерфейс
Программа использует библиотеку Rich для создания цветного интерфейса в терминале.

В нём отображаются ход регистрации, сообщения об ошибках, количество созданных аккаунтов и общая статистика выполнения.

• Сохранение результатов
Данные созданных аккаунтов сохраняются в формате JSON.

В записи могут входить адрес электронной почты, пароль, дата создания и текущий статус аккаунта. Документация отдельно предупреждает, что файл с этими сведениями содержит конфиденциальные данные и не должен публиковаться.
