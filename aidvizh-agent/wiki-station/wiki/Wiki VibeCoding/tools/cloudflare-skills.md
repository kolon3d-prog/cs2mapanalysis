# Cloudflare Skills — официальные скиллы для интеграции сервисов Cloudflare

Оригинальный пост:

При разработке под сервисы Cloudflare не забывайте про официальные скиллы: https://github.com/cloudflare/skills

Они охватывают почти все сервисы Cloudflare и очень часто обновляются. Каждый раз, когда мне нужно интегрировать какой-либо сервис Cloudflare, я сначала заглядываю туда — это очень удобно.

А для более продвинутых операций также доступен MCP-сервис.

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: официальные скиллы Cloudflare для агентов: покрытие почти всех сервисов (Workers, Pages, D1, R2 и др.), частое обновление; для продвинутых операций — MCP-сервер.

## Вывод

«Официальные скиллы вендора» — новый стандарт экосистемы (ср. Hermes Skills, CocoLoop): провайдеры сами упаковывают документацию в скиллы. Для нашей работы с Cloudflare (EdgeEver, cloudflare-imgbed) — первоисточник вместо самописных инструкций. Показательно: скилл от вендора = актуальная документация как код.
