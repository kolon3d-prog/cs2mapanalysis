# MD-This-Page — любая страница в идеальный промпт для ИИ

Оригинальный пост:

Превращаем ЛЮБУЮ страницу в идеальный промт для ChatGPT — вышло расширение, которое очищает сайты от рекламы, баннеров и другого мусора для отправки в нейронку.

Идеальная находка для тех, кто постоянно работает с ИИ. Забираем здесь (https://github.com/Ademking/MD-This-Page)
