# CAD Skills (text-to-cad) — агенты проектируют физические объекты

Оригинальный пост:

CAD Skills - навыки для агентов, которые позволяют им проектировать, анализировать и подготавливать к производству физические объекты по текстовым запросам или изображениям. Проект решает сложную инженерную задачу: он учит искусственный интеллект работать с профессиональными форматами файлов для трехмерного моделирования (CAD), робототехники и 3D-печати прямо внутри локального рабочего пространства.

Поддерживаемые форматы и стандарты файлов

Благодаря этим навыкам, агент умеет распознавать, генерировать, валидировать и конвертировать следующие форматы данных:

• Инженерное 3D-моделирование (CAD): Основным выходным форматом является промышленный стандарт STEP (или .stp), используемый для обмена данными между профессиональными САПР. Также поддерживаются поверхностные и полигональные сетки в форматах STL, 3MF и GLB.

• 2D-чертежи и раскрой: Для создания плоских контуров, шаблонов и макетов под лазерную или гидроабразивную резку ИИ использует промышленный формат векторной графики DXF.

• Управление производством и 3D-печать (CAM): Для подготовки моделей к 3D-печати система использует реальные CLI-инструменты слайсеров и генерирует готовый управляющий код в формате G-code (включая профилированные файлы для принтеров Bambu Lab).

• Робототехника и симуляция: Для описания кинематики, структуры и физических свойств роботов ИИ генерирует и связывает файлы форматов URDF (описание робота), SRDF (семантическое описание для планирования движений) и SDF (описание моделей и миров для симуляторов).
