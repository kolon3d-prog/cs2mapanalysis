# i-have-adhd — навык понятных и пригодных к действию ответов ИИ

Оригинальный пост:

🚀 Нашёл интересный open-source проект для тех, кого раздражают "простыни" от ИИ.

На GitHub появился i-have-adhd — навык, который меняет стиль ответов ИИ, делая их максимально понятными и пригодными к действию. Причём использовать его могут не только люди с СДВГ — многим просто удобнее получать информацию без лишней воды.

Что меняется:
• 🎯 сначала — конкретное действие или ответ;
• 🔢 задачи разбиваются на пронумерованные шаги;
• ⏱️ вместо «немного подождите» — реальные оценки по времени;
• 🚫 минимум отвлечений и длинных вступлений;
• ✅ после каждого шага видно, что уже сделано.

Проект уже поддерживает Claude Code, Codex, Gemini CLI, Cursor, GitHub Copilot, Zed и другие AI-инструменты. Для большинства достаточно установить навык и вызвать команду — переписывать свои промпты не придётся.
