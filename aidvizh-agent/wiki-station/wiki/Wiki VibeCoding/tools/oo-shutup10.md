# O&O ShutUp10 — отключение телеметрии и рекламы Windows в один клик

Оригинальный пост:

Windows 10/11 — нашли утилиту, которая сама отрубает всю рекламу, системный мусор и прочий ненужный хлам за 1️⃣ клик.

Фичи:
🔅 Отключение телеметрии Windows — блокирует сбор и отправку Microsoft данных о работе системы и пользователя;
🔅 Отключение рекламы и рекомендаций — убирает рекламные идентификаторы, подсказки и предложения Windows;
🔅 Контроль разрешений приложений — управляет доступом программ к камере, микрофону, геолокации и личным данным;
🔅 Отключение отслеживания активности — запрещает сбор истории действий и синхронизацию активности между устройствами;
🔅 Настройка Windows Update — позволяет управлять отдельными параметрами обновлений Windows;
🔅 Отключение облачных функций Microsoft — ограничивает связь системы с OneDrive, аккаунтом Microsoft и онлайн-сервисами;
🔅 Настройка Microsoft Defender — управляет отправкой данных, облачной проверкой и участием в программах анализа угроз;
🔅 Ограничение фоновой активности приложений — запрещает приложениям работать в фоне и собирать данные без необходимости;
🔅 Управление геолокацией и сенсорами — отключает определение местоположения и доступ к датчикам устройства;
🔅 Настройка Microsoft Office — уменьшает сбор диагностических данных и телеметрию офисных приложений;
🔅 Отключение Xbox-функций — позволяет убрать Game Bar, DVR и ненужные игровые сервисы Windows;
🔅 Настройка Windows 11 — отключает виджеты, новости, Bing-поиск и другие онлайн-компоненты.
