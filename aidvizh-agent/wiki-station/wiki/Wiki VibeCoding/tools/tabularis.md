# Tabularis — SQL-среда со встроенным MCP-сервером для агентов

Оригинальный пост (ключевые части):

Tabularis - это настольная рабочая среда SQL для:

→ PostgreSQL
→ MySQL и MariaDB
→ SQLite
→ DuckDB
→ ClickHouse
→ Redis
→ Firestore
→ И других баз данных через плагины

Но то, что действительно отличает её, так это встроенный сервер MCP.

Это позволяет напрямую подключать инструменты вроде:
→ Claude Desktop
→ Cursor
→ Windsurf
→ Других агентов, совместимых с MCP

После подключения агент может:
• Просматривать твои сохранённые подключения
• Перечислять базы данных и таблицы
• Читать столбцы, индексы и внешние ключи
• Понимать полную схему
• Писать SQL-запросы
• Выполнять их и возвращать результаты

Всё из того же интерфейса чата, который ты уже используешь для программирования.

Например, ты мог бы попросить:
«Проанализируй схему этой базы данных и объясни, как она организована».
«Напиши и выполни запрос, чтобы найти 10 клиентов с наибольшим доходом».
«Проверь этот запрос и скажи, почему он работает так медленно».

Кроме того, Tabularis включает:
→ Блокноты с SQL и Markdown
→ Переменные, общие для запросов
→ Графики с результатами
→ Визуальный редактор и генератор запросов
→ Диаграммы отношений
→ Визуальный EXPLAIN с интерактивными планами
→ Редактирование данных прямо в таблицах
→ Экспорт в CSV и JSON
→ SSH-туннели
→ Систему плагинов на любом языке
→ Text-to-SQL с локальными моделями через Ollama

Традиционные SQL-клиенты позволяют запрашивать базу данных.

Tabularis хочет, чтобы твои агенты ИИ могли понимать её и работать с ней.

https://github.com/tabularisdb/tabularis

- Пост готовый, ссылка не проверялась (по указанию автора).

- БД: PostgreSQL, MySQL/MariaDB, SQLite, DuckDB, ClickHouse, Redis, Firestore + плагины.
