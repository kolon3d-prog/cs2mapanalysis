# TrafficMonitor — скорость интернета и загрузка железа в панели задач

Оригинальный пост:

TrafficMonitor — скорость интернета прямо в панели задач
TrafficMonitor (https://github.com/zhongyang219/TrafficMonitor) добавляет в панель задач маленький индикатор с реальной скоростью приёма и отдачи данных. Полезно, когда качается большой файл или когда хочется понять, кто именно съедает канал.
Одной скоростью дело не ограничивается. Туда же можно вывести загрузку процессора и оперативной памяти, частоту процессора, загрузку видеокарты и диска, а также общий объём трафика за период — программа ведёт историю.

У утилиты две сборки, и разница между ними важная. Стандартная умеет показывать температуры процессора, видеокарты, диска и материнской платы, но для этого требует запуска с правами администратора. Версия Lite температуры не читает, зато обходится обычными правами — если мониторить нагрев вы не собираетесь, разработчик рекомендует именно её.

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: трей-индикатор Windows: скорость сети, загрузка CPU/RAM/GPU/диска, частота, трафик за период с историей.
- Две сборки: стандартная (температуры CPU/GPU/диска/материнки, требует админа) и Lite (без температур, обычные права — рекомендована, если нагрев не нужен).

## Вывод

Полезный мониторинг «на виду» без открывания диспетчера (ср. Task Manager Пламмера, но для Windows и легче). Разделение на Standard/Lite с честным «зачем тебе админ-права» — образцовое решение по безопасности: минимум привилегий по умолчанию.
