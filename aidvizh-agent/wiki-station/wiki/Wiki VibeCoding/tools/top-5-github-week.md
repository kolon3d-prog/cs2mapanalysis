# Топ-5 GitHub-репозиториев недели: Buzz, Ego Lite, Open Code Review, I Have ADHD, Editor

Оригинальный пост:

Топ-5 самых популярных GitHub-репозиториев этой недели:

Buzz (https://github.com/block/buzz) — опенсорс платформа для совместной работы разработчиков и AI-агентов над кодом.
Ego Lite (https://github.com/citrolabs/ego-lite) — браузер для AI-агентов, который использует ваши реальные вкладки, куки и авторизации.
Open Code Review (https://github.com/alibaba/open-code-review) — AI-инструмент от Alibaba для автоматического ревью Git-диффов и поиска ошибок в коде.

Editor (https://github.com/pascalorg/editor) — опенсорс 3D-редактор для проектирования и совместной работы над архитектурными проектами.
