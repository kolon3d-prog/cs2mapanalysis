# book-to-skill — техническая книга как низкоуровневая база знаний для агента

Оригинальный пост (ключевые части):

book-to-skill - разбивает технические книги в PDF/EPUB на слои, автоматически извлекая каркас основных концепций, ментальные карты и индекс глав, и напрямую превращает их в Agent Skill для Claude Code, GitHub Copilot CLI или Amp.

Нужная глава подгружается по запросу - это сокращает расход токенов в 20–50 раз и фактически превращает техническую книгу в «низкоуровневую базу знаний», к которой можно обращаться в любой момент.

💡 Ключевая ценность и возможности

1️⃣ Двухуровневая архитектура против галлюцинаций: генерируется обзорный файл размером около 3k токенов (ментальная модель + индекс) и отдельные файлы для каждой главы (подгружаются по необходимости, примерно по 1k токенов на главу). ИИ больше не нужно вслепую искать по всей книге - он сразу точно находит нужную главу и отвечает по ней.

2️⃣ Поддержка множества форматов и платформ: помимо PDF, поддерживаются EPUB, DOCX, Markdown и даже целые папки с архитектурной документацией / внутренними runbook’ами. Идеально стыкуется с терминальными инструментами, соответствующими открытому стандарту Agent Skills.

3️⃣ Локальный парсинг и приватность: извлечение данных выполняется сугубо локально, никакие приватные данные никуда не отправляются. Официально поддерживается парсинг через Docling, который отлично сохраняет блоки кода и таблицы Markdown.

⚠️ О чём стоит помнить и кому подойдёт
Подходит: разработчикам и независимым авторам, которые регулярно работают с объёмными техническими или архитектурными книгами, а также тем, кому нужно превращать внутренние ADR / архитектурную документацию команды в базу знаний для ИИ.

Совет из практики: для чисто текстовых «кирпичей» лучше использовать стандартный pdftotext - это ускорит работу; если же в книге много кода и таблиц, рекомендуем, как сказано в инструкции, доустановить Docling. После завершения работы достаточно набрать /your-book-slug прямо в Claude Code - и навык готов к использованию.
