# draw-your-font — свой почерк становится шрифтом через Claude Code

Оригинальный пост:

Свой почерк можно превратить в шрифт для компьютера с помощью Claude Code — вышел навык, о котором мечтали все школьники и студенты.

Всё, что нужно — записать алфавит и цифры на листике бумаги, сфоткать и закинуть Claude. ИИ распознает символы, удалит фон и превратит в готовый шрифт.

Забираем — здесь (https://github.com/danilo-znamerovszkij/draw-your-font).

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: навык: фото рукописного алфавита → Claude распознаёт символы, убирает фон → готовый шрифт.

## Вывод

«Свой почерк → шрифт» — милый и практичный кейс генерации (школьники/студенты — целевая аудитория). Для персонализации (шрифты бренда, конспекты) — просто и работает через VLM. Паттерн «фото → структурированный артефакт» (ср. Chandra OCR, Unstract).
