# Seedance Prompt Optimizer — навык промптов для Seedance 2.5 (ByteDance)

Оригинальный пост:

Навык для Claude, который создаёт оптимизированные промпты для Seedance 2.5.

Создан на основе официальных руководств ByteDance по составлению промптов и работе с моделью.

Навык охватывает:
• Основную структуру промпта: объект, сцена, стиль, камера и звук
• Работу с несколькими референсами и их привязку через @Image, @Video и @Audio
• Построение длинных видео по временным отрезкам с точным управлением сценами, например от 0 до 3 секунд, от 3 до 7 секунд и далее
• Синтаксис для редактирования и продолжения видео, а также создания плавных переходов между сценами
• Работу с ключевыми кадрами, раскадровками, черновой компоновкой и детальной проработкой сцены.

Как использовать:
Скачайте файл .skill.
В Claude откройте «Настройки» → «Возможности» и загрузите файл.
Используйте команду /seedance-prompt-optimizer в любом чате Claude.
