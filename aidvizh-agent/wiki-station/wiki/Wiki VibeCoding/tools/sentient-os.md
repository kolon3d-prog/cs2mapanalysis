# Sentient OS — «умный помощник», встроенный в macOS

Оригинальный пост:

Не для нищих:

Превращаем макбук в «умного» помощника: вышел Sentient OS (https://github.com/Sentient-OS-Labs/sentient-os) — встраивает ИИ в повседневную работу macOS.

ИИ анализирует файлы, скриншоты и переписки юзера и превращает их в локальную базу знаний. Каждое утро готовит подборку с ответами на забытые сообщения, напоминалками о списаниях за подписки и другими заметками.

Можно отдельно вызывать ассистента в течение дня и просить помочь с рабочими задачами. Вся персональная информация остается на маке, ИИ получает только обезличенные сводки.

## Вывод

«ОС с ИИ-памятью» (ср. Memora, Obelisk — память агентов; Sentient OS — память на уровне ОС): утренние дайджесты из личных данных. Обезличенные сводки — компромисс приватности. Для «второго мозга» на маке — интересный кейс; доступ к перепискам — доверять осознанно.
