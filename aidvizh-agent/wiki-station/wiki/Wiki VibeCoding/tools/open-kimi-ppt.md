# Open Kimi PPT Skill — неофициальный навык работы с PowerPoint для агентов

Оригинальный пост:

Open Kimi PPT Skill представляет собой неофициальный навык для ИИ агентов, предназначенный для создания, редактирования, чтения и экспорта презентаций PowerPoint.

Навык позволяет агентам вроде Codex, Claude Code, Cursor и WorkBuddy создавать полноценные презентации по текстовому описанию, редактировать существующие файлы PPTX, переносить оформление из шаблонов и восстанавливать презентации по изображениям или PDF документам.

По умолчанию, после выполнения задачи, создаются два результата:
• редактируемый проект в формате PPTD
• готовый файл PPTX, который можно открыть в Microsoft PowerPoint или WPS Office

Проект разработан методом обратного инжинеринга Kimi Slides, формата PPTD и протокола взаимодействия публичного веб редактора Kimi. Он не является официальным продуктом Kimi или Moonshot AI.

https://github.com/Binaryify/open-kimi-ppt-skill/tree/main

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: неофициальный навык для агентов (Codex, Claude Code, Cursor, WorkBuddy): создание/редактирование/чтение/экспорт презентаций PowerPoint.
- Возможности из поста: создание по текстовому описанию, правка существующих PPTX, перенос оформления из шаблонов, восстановление по изображениям/PDF.
- Результат по умолчанию: редактируемый проект PPTD + готовый PPTX (PowerPoint/WPS Office).
- Происхождение: обратный инжиниринг Kimi Slides, формата PPTD и протокола веб-редактора Kimi; не официальный продукт.
