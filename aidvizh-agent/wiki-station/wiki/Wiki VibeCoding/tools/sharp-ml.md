# SHARP-ML — 2D-фото в интерактивную 3D-сцену за секунды (Apple SHARP)

Оригинальный пост:

SHARP-ML - веб-приложение, которое превращает любую обычную 2D-фотографию в интерактивную 3D-сцену.

Проект построен на базе передовой ИИ-модели SHARP (от компании Apple), которая использует технологию 3D Gaussian Splatting для мгновенной генерации объемного пространства из одного кадра.

Зачем нужен этот проект?
Главная проблема классического создания 3D-моделей из фото (фотограмметрии) заключается в том, что программе требуется огромное количество снимков объекта с разных ракурсов и долгие часы вычислений.

SHARP-ML решает эту проблему, позволяя любому пользователю загрузить всего одну картинку формата PNG, JPG или WebP и получить готовое интерактивное 3D-пространство буквально за 1–10 секунд.

Это идеальный готовый шаблон (boilerplate) для разработчиков, которые хотят запустить собственный ИИ-сервис по генерации 3D-контента для игр, дизайна, электронной коммерции или дополненной реальности (AR).

Главные фишки и особенности
• Молниеносная генерация: Обработка изображения на сервере занимает считанные секунды, если графический чип уже прогрет.
• Полноценный интерактивный просмотр: Полученную сцену можно крутить мышкой, приближать, отдалять и перемещать во все стороны прямо в браузере.
• Эффективная серверная архитектура: Тяжелая нейросеть весом 1,4 ГБ разворачивается на мощных облачных видеокартах (NVIDIA A10G) через бессерверную платформу Modal. Вы платите за видеокарту только в те секунды, когда пользователь генерирует модель.
• Готовая бизнес-логика: В проект из коробки встроена авторизация через Google, система лимитов (например, 10 бесплатных генераций) и заготовки для подключения платежной системы Stripe, чтобы монетизировать сервис.
• Современный стек: Фронтенд написан на Next.js 16 и Tailwind CSS 4, база данных работает через Prisma и PostgreSQL, а за отрисовку 3D отвечает движок Three.js.

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: 2D-фото → интерактивная 3D-сцена (Apple SHARP + 3D Gaussian Splatting) за 1–10 сек; одна картинка вместо фотограмметрии с десятками снимков.
- Boilerplate для ИИ-сервиса: Google-авторизация, лимиты (10 бесплатных генераций), Stripe-заготовки.
- Архитектура: Modal (бессерверно, A10G, плата только за секунды генерации), Next.js 16, Tailwind 4, Prisma + PostgreSQL, Three.js.
