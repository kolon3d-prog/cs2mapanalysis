# ego lite — браузер для параллельной работы человека и ИИ-агентов

Оригинальный пост:

ego lite - это специализированный бесплатный браузер, созданный для параллельной работы человека и его ИИ-агентов (таких как Claude Code или Codex)

В отличие от стандартных фреймворков автоматизации, которые открывают новое пустое окно браузера, ego lite позволяет ИИ-агенту выполнять задачи в фоне, используя ваши текущие авторизации, куки и расширения, совершенно не мешая вашей основной работе.

Главные фишки

1. Единый браузер с разделением рабочих пространств
Вы можете спокойно читать статьи или смотреть видео на переднем плане, пока ваши ИИ-агенты параллельно выполняют рутинные задачи в изолированных фоновых вкладках. Программа исключает конфликты за управление курсором мыши или активными вкладками.

2. Мгновенный импорт данных из Google Chrome
При первом запуске браузер предлагает перенести данные из Chrome. Благодаря этому ИИ-агент сразу получает доступ к вашим рабочим аккаунтам, сайтам и сохраненным сессиям. Вам больше не придется заново проходить капчи или вводить пароли ради автоматизации сценариев.

3. Повышенная скорость и экономия токенов
Вместо отправки долгих пошаговых команд через терминал, ИИ-агент пишет цельный JavaScript-код, который браузер выполняет за один проход. Это ускоряет выполнение сложных комплексных задач до 2.5 раз и существенно снижает расходы на оплату API нейросетей.

4. Точные снимки страниц
Благодаря кастомизации на уровне ядра, ego lite создает качественные текстовые снимки веб-страниц. Это позволяет языковым моделям безошибочно «видеть» структуру сайта и корректно взаимодействовать даже со сложными элементами вроде глубоко вложенных фреймов.

На текущий момент полноценное приложение ego lite доступно для операционной системы macOS, а версии для Windows и Linux находятся в планах разработчиков. Код репозитория распространяется под свободной лицензией MIT.
