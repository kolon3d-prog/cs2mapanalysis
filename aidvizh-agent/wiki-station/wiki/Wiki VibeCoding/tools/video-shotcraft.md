# video-shotcraft — скилл, превращающий агентов в motion-дизайн студию

Оригинальный пост:

video-shotcraft — скилл, превращающий Claude Code и Codex в motion-дизайн студию

Устал делать промо-видео для продукта руками в After Effects или объяснять агенту с нуля, что такое хороший кадр? video-shotcraft это чинит.

Скилл для Claude Code и Codex: агент строит раскадровку, анимирует и озвучивает кинематографичный промо-ролик через Remotion — с реальными скриншотами страниц, 2.5D-движением камеры, монтажом под биты и киношным саунд-дизайном.

106 карточек-рецептов кадров и 161 превью движения — библиотека готовых мотивов, из которых агент собирает нужную сцену под задачу.

Готовый шаблон "Ink Press" из коробки: 36.2 сек, 1920×1080, 30fps, 10 шотов в стиле paper-ink-amber с тайтлами, переходами и звуком.

Галерея кадров онлайн: можно искать, фильтровать и копировать имена шот-карточек прямо в браузере.

Установка в одну строку:
npx skills add Vincentwei1021/video-shotcraft
