# HermesOffice — офисный пакет с агентом как базовой функцией

Оригинальный пост:

HermesOffice - это офисный пакет с открытым исходным кодом для macOS и Windows, включающий текстовый процессор, табличный редактор, инструменты для презентаций и работу с PDF.

Его главная особенность заключается в глубокой интеграции автономного агента как базовой функции интерфейса, а не в виде обычного бокового чата.

Проект представляет собой форк другого офисного пакета - GenOffice от Genspark.

Программа написана на TypeScript и работает на базе Electron. Разработчики используют подход «микро-патчей» для сохранения оригинальной структуры файлов Microsoft Office (.docx, .xlsx, .pptx).

• Архитектура агента: Агент обладает собственной памятью, навыками и инструментами, а также поддерживает протокол MCP (Model Context Protocol).
• Работа в текстовом редакторе: Агент редактирует текст точечно на уровне отдельных абзацев. Система автоматически сохраняет снимки состояния (snapshots) и наглядно подсвечивает разницу (diffs) между версиями текста.
• Работа с таблицами, слайдами и PDF: В этих приложениях агент управляет данными через механизм вызова инструментов (tool-calling), считывая текущее состояние открытого документа.

Состав пакета
HermesOffice Docs - редактор документов .docx с постраничным отображением и возможностью отслеживания правок.
HermesOffice Sheets - табличный редактор .xlsx на базе открытого движка Univer. Импорт и экспорт ускорены за счет sidecar-модуля на языке Rust. Поддерживает сводные таблицы, срезы и трассировку формул.
HermesOffice Slides - редактор презентаций .pptx со встроенным движком рендеринга и работы со шрифтами.
HermesOffice PDF - приложение для просмотра и базового редактирования PDF (добавление аннотаций, подписей, https://github.com/criptogus/HermesOffice

## Вывод

Самый показательный пример «агент встроен в интерфейс, а не приклеен чатом»: точечные правки с диффами вместо «перепиши весь документ». Микро-патчи для сохранения нативной структуры Office-файлов — важная инженерная деталь (совместимость с оригиналом). Тренд: офисные пакеты становятся агентными средами.
