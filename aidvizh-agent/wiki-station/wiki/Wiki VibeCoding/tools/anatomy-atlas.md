# Интерактивный анатомический атлас: обучение будущего от гения из Твиттера

Оригинальный пост:

Учёбу будущего представил гений из Твиттера: он показал обучение с ИИ, дропнув интерактивный анатомический атлас.

В приложении можно крутить 3D-модели органов, изучать их строение и читать, что это такое и как оно работает. В конце есть тест для проверки новых знаний.

Для создания атласа разраб использовал нейронки: GPT-5.6 Sol для кода, GPT Image для изображений органов и ещё ИИ для создания 3D-моделей.

Пост уже репостнул сооснователь OpenAI Грег Брокман. Протестить революцию в обучении можно тут, (https://anatomy-livid.vercel.app/) а GitHub пощупать тут. (https://github.com/thebuggeddev/anatomy)
