# OmniRoute — бесплатный доступ к ИИ через единый API

Оригинальный пост:

Проект для бесплатного доступа к ИИ. 😧

OmniRoute объединяет все сервисы с бесплатным тарифом в один API-эндпоинт.

✓ Работает с Claude Code, Codex и Cursor
✓ Поддерживает сжатие токенов
✓ Доступно 50 провайдеров

100% опенсорс (https://github.com/diegosouzapw/OmniRoute)

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: единый API-эндпоинт поверх бесплатных тарифов 50 провайдеров; сжатие токенов; совместим с Claude Code/Codex/Cursor; опенсорс.

## Вывод

Агрегатор «халявы» (ср. FreeLLM — каталог, OmniRoute — рабочий роутер): единая точка доступа к бесплатным тарифам. ⚠️ Бесплатные тарифы нестабильны (лимиты, блокировки) — для продакшена ненадёжно, для экспериментов — удобно. Паттерн «роутер провайдеров» полезен и для платных (fallback-цепочки).
