# Persona — голосовое общение с ИИ в виде живого 3D-персонажа

Оригинальный пост:

Persona - десктопный проект, который превращает голосовое общение с ИИ в живого 3D-персонажа прямо на вашем экране.

Вместо того чтобы разговаривать с безликим голосом на фоне, вы взаимодействуете с визуальным компаньоном, который реагирует на происходящее параллельно с вашей работой.

✨ Возможности
🧑‍💻 Кроссплатформенное приложение для ПК.
🎙 Работает одновременно с голосовым общением в реальном времени.
🧍 Поддерживает кастомизацию VRM-персонажей и VRMA-анимации.
🖥 Постоянно находится поверх других окон с поддержкой плавающего режима

🔊 Фокус на конфиденциальности
✅ Никакой записи с микрофона.
✅ Никакой расшифровки речи в текст.
✅ Никакой загрузки аудио в сеть.
✅ Никакого сохранения истории диалогов.

Проект просто фиксирует воспроизведение голоса и анимирует персонажа локально на вашем устройстве.

🛠 Создано для разработчиков
⚡️ Десктопное приложение на базе Electron.
🎮 3D-рендеринг с аппаратным ускорением.
🪟 Поддержка Windows, macOS и Linux.
🎨 Возможность заменить стандартного персонажа на собственную VRM-модель и настроить свои анимации.

Проект всё еще находится на ранней стадии разработки, поэтому запустить его «из коробки» прямо сейчас не получится.

https://github.com/xikhar/persona

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: голос + 3D-персонаж (VRM/VRMA), поверх окон; реагирует на происходящее.
- Приватность (из поста): НЕТ записи микрофона, НЕТ STT, НЕТ загрузки аудио, НЕТ истории — анимирует по факту воспроизведения голоса локально.
- Технологии: Electron, аппаратный 3D; Windows/macOS/Linux; ранняя стадия.

## Вывод

Иной подход к приватности: не обрабатывать речь вообще (анимация по аудио-сигналу) — «ноль данных». Для персонажей-компаньонов (ср. Open-LLM-VTuber) — свежая идея. Ранняя стадия — учитывать.
