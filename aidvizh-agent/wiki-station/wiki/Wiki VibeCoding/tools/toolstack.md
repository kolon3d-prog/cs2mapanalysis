# toolstack — каталог 2000 инструментов для разработки

Оригинальный пост:

toolstack — каталог инструментов для разработки, в котором собрано 2000 библиотек, сервисов, платформ и утилит. Он помогает быстрее находить подходящие решения для конкретной задачи и не тратить время на просмотр десятков разрозненных подборок.

Инструменты можно искать по названию, описанию и сценарию использования, а также фильтровать по категории, типу продукта, способу развёртывания, наличию бесплатного тарифа и другим параметрам. Для каждого инструмента указаны назначение, основные возможности, модель распространения, условия использования и ссылка на официальный сайт.

Подходящие инструменты можно добавлять в избранное, а отдельный режим графа позволяет изучать каталог как дерево категорий и связей. toolstack подходит для выбора технологий, изучения новых решений и сравнения вариантов перед началом разработки.
