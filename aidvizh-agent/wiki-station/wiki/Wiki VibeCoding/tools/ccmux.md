# ccmux — тонкий TUI-слой поверх tmux для Claude Code и Codex

Оригинальный пост:

ccmux — тонкий TUI-слой поверх tmux для тех, кто держит Claude Code/Codex открытыми весь день 🖥🤖

📌 Не отдельный мультиплексор, а надстройка над уже установленным tmux — то, чего не хватает при работе с AI-агентами часами напролёт, без лишнего конфига.

🌳 Рекурсивные сплиты (бинарное дерево), ресайз перетаскиванием, до 16 панелей на вкладку.

🟠 Панель с Claude Code сама подсвечивается оранжевым, пока агент работает — без плагинов, автоматически.

📊 Живой контекст-бар из локальных JSONL-логов Claude Code — жёлтый на 70%, красный на 90%.

🤖 Суб-агент через Task-тул — его тип и текущий тул сразу видно в заголовке панели.

⌨️ Попап-пикер сессий: Ctrl+P (с префиксом tmux) или Alt+P без него.

📋 Требования:
— Установленный tmux (ccmux — надстройка, не замена)
— Bun
— git 2.31+ опционально (для ветки/worktree)
— Платформа: macOS/Linux

⚠️ Под именем ccmux на GitHub минимум 4 разных проекта разных авторов — этот пост про epilande/ccmux.

🔗 GitHub: github.com/epilande/ccmux
