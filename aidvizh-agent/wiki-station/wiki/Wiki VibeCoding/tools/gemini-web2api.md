# gemini-web2api — веб-Gemini как OpenAI-совместимый API

Оригинальный пост:

превращает веб-интерфейс Gemini в API-интерфейс, совместимый с OpenAI, который работает практически с любым ИИ-клиентом.

1. Имитирует запросы от веб-версии Gemini.
2. Вызывает внутренний протокол StreamGenerate, используемый веб-версией Gemini.
3. Преобразует запросы формата OpenAI во внутренний формат Gemini.
4. Упаковывает ответы Gemini в формат OpenAI API.

• Нет поддержки изображений: Через этот API нельзя передавать картинки. Веб-интерфейс Google использует сложный проприетарный RPC-протокол для загрузки файлов (WIZ/ProcessFile), который авторам не удалось повторить в коде.
• Ограничение бесплатного аккаунта: Без платной подписки на Gemini Advanced (для которой нужно вручную вытаскивать Cookie из браузера) запросы к продвинутым моделям (вроде Pro) будут незаметно для вас перенаправляться на обычную модель Flash
• Риск блокировок: Google может временно заблокировать IP-адрес или аккаунт при слишком частых и однотипных запросах, так как алгоритмы защиты увидят автоматизацию действий пользователя.

## Вывод

Классический «web2api»-хак: бесплатный доступ к модели через веб-морду (ср. gemini-web2api vs официальный API). ⚠️ Тихое перенаправление Pro→Flash без предупреждения — критично знать. Наш стандарт: для продакшена — официальные API; такие обёртки — только для экспериментов с пониманием рисков блокировок.
