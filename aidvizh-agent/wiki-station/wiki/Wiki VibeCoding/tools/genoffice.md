# GenOffice — офисный пакет, спроектированный вокруг ИИ-редактирования

Оригинальный пост:

GenOffice - это офисный пакет нового поколения для macOS и Windows, созданный поисковым ИИ-стартапом Genspark.

В отличие от привычных Microsoft Office или Google Документов, куда функции ИИ были добавлены позже в виде обычных чат-ботов сбоку, GenOffice изначально спроектирован вокруг ИИ-редактирования как главного рабочего процесса.

Что входит в пакет
Проект состоит из пяти Electron-приложений, работающих на едином движке:

• GenOffice Docs - текстовый редактор для работы с файлами .docx.
• GenOffice Sheets - табличный редактор для файлов .xlsx.
• GenOffice Slides - приложение для создания презентаций .pptx.
• GenOffice PDF - инструмент для просмотра, комментирования и редактирования PDF-файлов.
• GenOffice - общая оболочка со стартовым экраном, системой вкладок и автообновлением.

Главные фишки

1. Умная интеграция ИИ прямо в структуру документов
Каждое приложение содержит встроенную ИИ-панель. В текстовом редакторе ИИ умеет изменять контент на уровне отдельных блоков и абзацев, сохраняя историю версий и наглядно показывая разницу (diff). В таблицах, презентациях и PDF работает ИИ-агент, который понимает текущее состояние вашего файла и может выполнять сложные комплексные команды пользователя.

2. Безупречное сохранение оригинальной структуры файлов
Главная техническая гордость разработчиков заключается в концепции «точечных изменений». Когда вы открываете файл от Microsoft Office и редактируете его с помощью ИИ, нейросеть переписывает только те абзацы, которые вы изменили. Весь остальной документ, включая стили, макеты, формулы и скрытые данные, сохраняется байт в байт. Это гарантирует, что ИИ никогда случайно не «сломает» верстку сложного документа.

3. Отсутствие необходимости в личных API-ключах
Приложения работают через единую учетную запись Genspark. Все запросы к языковым моделям маршрутизируются через их облачный сервис, поэтому пользователю не нужно покупать и настраивать собственные ключи API от OpenAI или Anthropic
