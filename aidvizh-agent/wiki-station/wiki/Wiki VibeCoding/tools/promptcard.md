# PromptCard — расширение: изображение → восстановленный промпт

Оригинальный пост:

Разбираем промты для генерации ЛЮБЫХ фото в любом стиле — вышло расширение PromptCard для браузера Chrome.

Оно анализирует изображение и восстанавливает промт, по которому оно было создано. После этого его можно использовать для генерации практически идентичной картинки в любой нейросети.

Забираем помощника в обработке своих фоток здесь (https://chromewebstore.google.com/detail/pdiegjclbkenbildadfjggoidpkplbmd?utm_source=item-share-cp).
