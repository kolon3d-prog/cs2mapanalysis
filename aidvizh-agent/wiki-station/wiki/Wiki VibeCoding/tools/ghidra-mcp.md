# GhidraMCP — реверс-инжиниринг через LLM с инструментами Ghidra

Оригинальный пост:

Вам бы просто дописать свой проект, который вы кодите уже хуеву тучу времен:

GhidraMCP (https://github.com/LaurieWired/GhidraMCP) — это сервер Model Context Protocol, который позволяет большим языковым моделям самостоятельно проводить реверс-инжиниринг приложений.

Он предоставляет множество инструментов из основных функциональных возможностей Ghidra для клиентов MCP.

## Вывод

MCP открывает мощные инструменты реверса агентам (ср. Reverse Skill — маршрутизатор методологии, GhidraMCP — конкретный инструмент). Связка «агент + Ghidra» — реверс по промпту: «разбери эту функцию». Для наших реверс-задач (js-deobfuscation, black-box-to-blueprint) — возможный инструмент.
