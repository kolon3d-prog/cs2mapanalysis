# Agency Agents — установщик 230+ агентов-персон в кодинг-инструменты

Оригинальный пост:

Agency Agents — нативный установщик каталога AI-агентов-персон в ваши кодинг-инструменты 🧩🤖

📚 230+ готовых агентов-персон (markdown-файлы с ролью, процессом и результатами) по 12 дивизионам: инженерия, дизайн, маркетинг, продажи, продукт, QA и другие.

🖥 Нативное приложение на Tauri + Svelte для macOS, Linux и Windows — ставит агентов в Claude Code, Cursor, Codex, Gemini CLI и др.

🔍 Конвертеры под каждый инструмент дают byte-for-byte совпадение с апстрим-конвертером agency-agents; при перезаписи каждый файл сначала бэкапится.

📊 Отслеживает состояние каждого установленного файла: актуален, устарел, изменён вручную, удалён или сторонний — видно, что поменялось в обход приложения.

📁 Projects — можно ставить агентов не глобально, а на конкретный репозиторий.

🔐 Опциональный GitHub OAuth (Device Flow), токены — только в системном keychain.

🔓 MIT, open source, local-first, без телеметрии

🔗 Сайт: agencyagents.app
🔗 GitHub: github.com/msitarzewski/agency-agents-app
