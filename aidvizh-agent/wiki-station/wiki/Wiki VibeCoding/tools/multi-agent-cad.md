# Multi Agent CAD (и Cadena) — текст в CAD: мультиагентная система для 3D-печати

Оригинальный пост:

Любая 3D сетка в каком то смысле похожа на скомпилированный бинарный файл: её можно напечатать и использовать, но она уже зафиксирована. Нельзя просто сказать: «сделай это отверстие на 2 мм шире».

Cadena как раз создана для решения этой проблемы. По сути, это декомпилятор для 3D моделей, который шаг за шагом восстанавливает из обычной сетки редактируемую параметрическую CAD модель вместе с последовательностью операций её построения.

Multi Agent CAD - это мультиагентная система для преобразования естественного языка в CAD, который позволяет создавать пригодные для 3D печати модели примерно за $0,15 за штуку.

В системе одновременно работают четыре специализированных агента.

По результатам тестирования, Multi Agent CAD использует примерно в 116 раз меньше токенов, чем CAD Skills, 896 тысяч против 103,9 миллиона, а стоимость инференса оказывается примерно в 13 раз ниже.

При этом показатель успешного прохождения функциональных проверок достигает 99,3%, 140 из 141 теста, против 97,9% у CAD Skills.

Проект начался с того, что наша лаборатория пригласила Guanxing благодаря его опыту в CAD для создания связанных между собой деталей в проекте по обучению роботов.

Однако его вклад вышел далеко за рамки обычного моделирования. Он объединил опыт работы с CAD и проектирование агентных рабочих процессов, что помогло создать эту мультиагентную систему.

Проект только релизнулся. https://github.com/Pan-Chera/Multi-Agent-CAD

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Два инструмента в посте:
  - **Cadena** — «декомпилятор для 3D-моделей»: из обычной сетки восстанавливает параметрическую CAD-модель + последовательность операций построения (сетку можно редактировать, а не только печатать).
  - **Multi Agent CAD** — мультиагентная система «естественный язык → CAD»: 4 специализированных агента, пригодные для 3D-печати модели ~$0.15/шт.
- Метрики (из поста, против CAD Skills): в 116× меньше токенов (896K vs 103.9M), ~13× дешевле инференс, 99.3% функциональных проверок (140/141) против 97.9%.
- История: началось с задачи обучения роботов (связанные детали), автор Guanxing объединил CAD-опыт и агентные воркфлоу. Проект только релизнулся.
