# Decimen — передача файлов между телефонами через QR-пакеты

Оригинальный пост:

Теперь передавать любые файлы с телефона на телефон можно без Wi-Fi, Bluetooth и доступа к интернету — на GitHub вышло гениальное приложение Decimen.

— Отправляемый файл разбивается на сотни мелких фрагментов (пакетов);
— Затем для каждого пакета генерируется свой QR-код, который расшифровывает данные и воссоздает их;
— QR-коды сменяются так быстро, что «загрузка» достигает скорости в ~128 кб/с;
— При этом есть фича для восстановления потерянных пакетов — на случай, если какой-то из сотен QR-кодов считается неправильно.

Теперь только так и делимся любимыми мемами — забираем (https://github.com/bashalarmistalt/decimen-optical-transfer/).

## Вывод

Гениальный в простоте трюк: экран камеры как канал данных (ср. LocalSend — но там нужна сеть). Скорость 128 кб/с — для мемов и мелких файлов ок, для больших — медленно. Полезно в офлайне/на событиях. Паттерн «избыточность + восстановление пакетов» — правильная инженерия для ненадёжного канала.
