# Mintlify Index — поисковый MCP-слой для технических знаний

Оригинальный пост:

Представляем Mintlify Index: первый поисковый слой для технических знаний, который получает данные напрямую от издателей и построен на экосистеме Mintlify, объединяющей более 200 000 организаций.

В нашем сравнительном тесте с Context7 агенты, использующие Mintlify Index, выполняли задачи в два раза быстрее и показывали на 9% более высокую фактическую точность.

Сегодня мы открываем MCP сервер Mintlify Index для всех желающих. Попробовать его можно полностью бесплатно.

Mintlify Index работает с 9 000 страниц самых посещаемых документаций, размещённых на платформе Mintlify. Среди них документация Anthropic, Microsoft, Notion, Kimi, Cognition, Polymarket, X и многих других.

Если запрос касается продукта, представленного в Index, система направляет его к актуальной документации, которую поддерживает сам издатель. Все остальные запросы отправляются в обычный веб поиск.

## Вывод

Mintlify Index — пример «документация как источник истины» через MCP: агенту не нужно грепать интернет в поисках актуальных доков — издатель сам поддерживает данные. Для нас интересно как возможный источник в веб-ресёрче (актуальные доки вместо случайных страниц). Цифры из поста — маркетинг автора, но сам паттерн (MCP + официальные доки) сильный.
