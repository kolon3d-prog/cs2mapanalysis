# FluentTweaker — выключение хлама Windows без знаний (60 пунктов)

Оригинальный пост:

Вырубаем всю рекламу и системный мусор в Windows — нашли сервис, который отключит весь хлам, мешающий быстрой работе ОС на уровне реестра.

• Знаний кода или ОС вообще не нужно: тыкаем в один из 60 пунктов и просто выключаем его. Перезапускаем комп, и все изменения сохранятся.
