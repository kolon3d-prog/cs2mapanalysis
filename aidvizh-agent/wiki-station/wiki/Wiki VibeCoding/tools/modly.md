# Modly — любое фото в 3D-модель на своём GPU

Оригинальный пост:

Modly - приложение, которое превращает любое фото в 3D-модель.

Работает полностью на вашем собственном GPU.

⚡️ Работает на Windows, Linux и Apple Silicon macOS.
🔄 Визуальный рабочий процесс с узлами: Изображение → Генерация сетки → Добавить в сцену
🛠 Сглаживайте, упрощайте и оптимизируйте (децимируйте) полигональную сетку прямо в приложении.
🧩 Поддерживает внешние расширения ИИ-моделей для различных стилей генерации.

Отлично подходит для:
🎮 Разработчиков игр
🎨 3D-художников
🖨 3D-печати
🤖 Создателей ИИ-контента
