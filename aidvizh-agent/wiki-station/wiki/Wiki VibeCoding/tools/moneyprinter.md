# MoneyPrinterTurbo — автогенерация видео для TikTok/Reels/Shorts

Оригинальный пост:

Инструмент, который автоматически генерирует готовые видео для TikTok, Reels и YouTube Shorts.

Он объединяет в один рабочий процесс генерацию сценария, озвучку, создание субтитров, подбор визуальных материалов и монтаж. Это позволяет получать готовые к публикации ролики всего за несколько минут.

Как это работает?
→ Автоматически пишет сценарий на основе заданной темы
→ Находит подходящие HD-видео без авторских прав для визуального ряда
→ Создает озвучку, генерирует субтитры и подбирает фоновую музыку
→ Монтирует и экспортирует готовый ролик для TikTok, Reels или Shorts

Как его установить
→ Скачайте репозиторий с GitHub
→ Используйте пакет быстрого запуска для Windows или Docker для любой другой операционной системы
→ Настройте интеграцию со своей любимой языковой моделью (Claude, GPT, Gemini, DeepSeek...)
→ Откройте веб-интерфейс и начинайте создавать видео

Программу также можно запустить в Google Colab, если вы не хотите ничего устанавливать на свой компьютер.
