# Cursor Router — умный роутер моделей под задачу

Оригинальный пост:

Cursor Router (https://cursor.com/blog/router)

Умный роутер от Cursor. Автоматически подбирает модель под задачу. рутину кидает на дешёвые, сложные штуки на топовые.

• три режима: Intelligence (максимум мощи), Balance (баланс), Cost (минимум токенов)
• админы задают правила для команды, блокируют или разрешают модели
• учитывает кэш. не тратит лишнее на повторные контексты
• работает везде: десктоп, веб, iOS, CLI, SDK

## Вывод

Роутинг моделей становится продуктовой функцией (ср. sol-luna-workflow — наш ручной роутинг, FreeLLMAPI, OmniRoute): автоматизация выбора «дешёвое для рутины, дорогое для сложного» — стандарт экономии. Админ-правила для команды — контроль бюджета. Для нас: паттерн подтверждён.
