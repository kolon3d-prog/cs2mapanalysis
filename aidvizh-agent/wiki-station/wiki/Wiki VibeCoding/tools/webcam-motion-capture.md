# Webcam Motion Capture — захват движений для VTuber с обычной веб-камеры

Оригинальный пост:

Webcam Motion Capture - это специализированный AI-сервис для виртуальных стримеров (VTuber), аниматоров и создателей контента, которое позволяет анимировать 3D-аватара с помощью обычной веб-камеры или смартфона.

Ключевые возможности сервиса

• Захват движений без оборудования: нейросеть распознает движения рук, пальцев, головы, мимику лица, взгляд, моргание и движения верхней части тела. Дорогие костюмы или VR-трекеры не требуются.

• Интеграция со сторонними программами: данные трекинга можно передавать в реальном времени в популярный софт для витуберов (например, VSeeFace) через протокол VMC, а также в игровые движки Unity и Unreal Engine.

• Экспорт в 3D-форматы: движения можно записывать и сохранять в файл формата FBX для последующей работы и создания анимаций в Blender, Maya, 3ds Max и других 3D-редакторах.

• Поддержка Perfect Sync: программа совместима с iOS-приложениями, которые используют Face ID на iPhone/iPad для передачи высокоточной и детализированной мимики на аватар.

• Коммерческое использование: сервис официально разрешает монетизировать созданный с его помощью контент (стримы на YouTube/Twitch, видео, игры).
