# Sourcebot — селфхост-поисковик по репозиториям без утечки кода

Оригинальный пост:

Разрабы запилили Sourcebot (https://github.com/sourcebot-dev/sourcebot) — селфхост-поисковик по репозиториям, который не стучит на корпорацию и не обучается на твоих секретах 🕵️‍♂️.

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: self-hosted поиск по репозиториям — разворачивается у себя, поиск идёт по собственному коду.
- Ключевое позиционирование из поста: приватность — не отправляет данные наружу («не стучит на корпорацию»), не обучается на ваших секретах.

## Вывод

Для команд с закрытым кодом (или с NDA-контрактами, где нельзя гонять код через облачные сервисы) селфхост-поиск по репозиториям — необходимый инструмент. Та же логика, что и у self-hosted аналогов Copilot/Code Search: контроль над кодом важнее удобства облака.
