# Bolt Slides — скилл интерактивных HTML-презентаций

Оригинальный пост:

🔥Claude Code и Codex научили делать топовые презентации — нашли скилл, который прямо из коробки генерирует красивые HTML-презентации.

Фичи:
🔅 Создаёт презентации по одному текстовому запросу;
🔅 Делает каждый слайд интерактивным веб-приложением;
🔅 Добавляет рабочие кнопки, формы, графики и другие интерактивные элементы;
🔅 Поддерживает 3D-эффекты и плавные анимации;
🔅 Показывает данные в реальном времени через API;
🔅 Автоматически адаптирует презентацию под любые экраны;
🔅 Сам подбирает современный дизайн и макеты слайдов;
🔅 Работает с Claude Code, Codex, Cursor, Bolt и другими ИИ-агентами;
🔅 Позволяет делиться презентацией по обычной ссылке без экспорта.

Забираем тут (https://github.com/stackblitz/bolt-slides).

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: скилл HTML-презентаций: промпт → интерактивные слайды (кнопки/формы/графики/3D), live-данные через API, адаптив, шаринг по ссылке.
- Совместимость: Claude Code, Codex, Cursor, Bolt.

## Вывод

«Презентация = веб-приложение» (ср. PPT Master — нативный PPTX; Bolt Slides — интерактивный HTML): каждый слайд живой. Для продуктовых демо/питчей — сильный формат. Интерактивность и live-данные — то, что PPT не умеет. Для нас: HTML-презентации с рабочими элементами — интересный формат доков.
