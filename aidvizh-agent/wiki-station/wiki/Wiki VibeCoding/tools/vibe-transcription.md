# Vibe — бесплатная транскрипция аудио/видео локально

Оригинальный пост:

Превращаем любое аудио и видео в текст на лету — нашли бесплатное приложение Vibe, которое упростит жизнь студентам и белым воротничкам.

— Работает на локальных моделях Whisper, Nemotron 3.5 и Parakeet TDT v3 — все данные остаются на вашем компьютере;
— Понимает сотни языков, включая русский;
— Справляется даже с записями, на которых несколько спикеров;
— Результат можно сохранить во всех возможных форматах: SRT, VTT, TXT, HTML, PDF, JSON и DOCX;
— Поддерживает macOS, Windows и Linux;
— Установка в пару кликов через releases;
— С открытым кодом и бесплатно.
