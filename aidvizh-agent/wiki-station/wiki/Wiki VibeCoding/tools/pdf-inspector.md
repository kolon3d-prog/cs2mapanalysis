# pdf-inspector — самый быстрый парсер PDF в Markdown (Firecrawl)

Оригинальный пост:

🔥 Firecrawl выпустил в опенсорс самый быстрый парсер PDF — pdf-inspector конвертирует документы в формат Markdown за долю секунды.

→ Каждая страница обрабатывается за 0,002 секунды.
→ По последним тестам PDF на 200 страниц займет рекордные 0,47 (!) секунды.
→ Корректно извлекает заголовки, таблицы и всю структуру документа.
→ Можно напрямую интегрировать в свой RAG и пайплайны.
→ Написан на Rust, запускается локально на макбуке в браузере.

Сохраняйте — тут (https://github.com/firecrawl/pdf-inspector).
