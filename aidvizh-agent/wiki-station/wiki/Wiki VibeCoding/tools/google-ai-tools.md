# 15 инструментов Google AI, которые стоит попробовать

Оригинальный пост:

Вот 15 инструментов Google AI, которые стоит попробовать:

1. Ручки
https://labs.google.com/pomelli/
Превращает ваш веб-сайт в полноценный фирменный стиль, а затем генерирует соответствующие публикации в социальных сетях, маркетинговые кампании и изображения.

2. Сшить
https://stitch.withgoogle.com/
Опишите желаемый пользовательский интерфейс, и программа сгенерирует готовые к использованию HTML, CSS, Tailwind, а также экспорт в Figma.

3. Опал
https://opal.google/
Создавайте приложения с искусственным интеллектом и многоэтапные рабочие процессы, используя простой английский язык вместо кода.

4. Антигравитация
https://antigravity.google/
Рабочая среда для программирования с использованием ИИ, позволяющая планировать, редактировать несколько файлов и создавать полноценные приложения из одной командной строки.

5. Микшерный пульт
https://labs.google.com/mixboard/
Создавайте, перерабатывайте и редактируйте изображения, полученные с помощью ИИ, на бесконечном холсте для создания мудбордов и визуальных концепций.

6. Дискотека
https://labs.google/disco
Превращает открытые вкладки браузера в интерактивные приложения с искусственным интеллектом.

7. NotebookLM
https://notebooklm.google/
Загружайте PDF-файлы, видео, документы или заметки и получайте краткие обзоры, учебные пособия, викторины и обсуждения в формате подкастов.

8. Учитесь на своих ошибках.
https://learnyourway.withgoogle.com/
Создает персонализированный курс по любой теме с использованием искусственного интеллекта, включающий уроки, аудиоматериалы, викторины и интеллект-карты.

9. Google AI Studio
https://aistudio.google.com/
Создавайте прототипы и разрабатывайте приложения с использованием искусственного интеллекта с помощью Gemini, используя бесплатный API-ключ и огромное контекстное окно.

10. Жюль
https://jules.google/
Создайте для него задачу на GitHub, и он напишет код, внесет изменения и откроет запрос на слияние.

11. Близнецы 11
https://github.com/google-gemini
Используйте Gemini прямо из терминала, чтобы понять структуру своего кода, выполнять команды и ускорить разработку.

12. Code Wiki
http://codewiki.google/
Создайте постоянно обновляемую вики-страницу для любого общедоступного репозитория GitHub с архитектурными схемами и пояснениями к коду, созданными с помощью искусственного интеллекта.

13. Firebase Studio
https://firebase.studio/
Рабочая среда для искусственного интеллекта, предназначенная для создания серверных служб и облачных приложений.

14. Gemini Code Assist
https://codeassist.google/
Бесплатный помощник по программированию на основе искусственного интеллекта от Google с автозавершением кода, проверкой кода и интеграцией с IDE.

15. Gemini Code Assist для GitHub
https://github.com/apps/gemini-code-assist
Просматривайте запросы на слияние, объясняйте код и ускоряйте разработку прямо в GitHub. 🚀
