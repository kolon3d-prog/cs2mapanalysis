# Яндекс 360 Трекер — платформа плагинов с вайбкодингом

Оригинальный пост:

Тулзу для кастомизации Трекера выпустил Яндекс 360 — это платформа плагинов с возможностью вайбкодинга.

Внутри:
🔅 Готовые плагины из каталога. Ставим в один клик;
🔅 Любой плагин можно вайбкодить на ЛЮБОЙ нейронке на стороне юзера;
🔅 Результат виден сразу в интерфейсе, а правки вносятся в реальном времени;
🔅 Плагин видит только те данные, к которым есть доступ у юзера — права контролит админ.

Например, можно сделать плагин учёта времени, который посчитает потраченное на задачу время и сформирует отчёт.

Следующий шаг – навайбкодить плагин, который сам закроет все таски.

🙂 Не баг, а фича (https://t.me/bugnotfeature)

## Контекст

- Пост готовый, ссылки нет (по указанию автора).
- Что: платформа плагинов Яндекс 360 Трекера: каталог (1 клик), вайбкодинг плагинов на любой нейронке на стороне юзера, live-правки.
- Безопасность: плагин видит только данные с доступом юзера; права контролит админ.
- Пример: плагин учёта времени (потраченное время по задаче → отчёт).

## Вывод

Корпоративный продукт легализует «вайбкодинг»: пользователи пишут расширения промптами, админ контролит права. Модель безопасности «плагин видит только своё» — правильный принцип (least privilege). Для команд на Яндексе — новый уровень кастомизации.
