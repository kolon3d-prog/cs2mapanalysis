# CloudFlare-ImgBed — хостинг картинок на Cloudflare + Docker

Оригинальный пост:

Обычно для создания собственного хостинга картинок приходится вручную связывать разные хранилища (Telegram, Discord, Cloudflare R2, S3, WebDAV), настраивать файловый менеджер и API. Проект CloudFlare-ImgBed собирает всё это в единое готовое решение, которое работает сразу после деплоя.

CloudFlare-ImgBed - это решение для хостинга файлов на базе Cloudflare и Docker, которое заменяет собой сразу три инструмента: классический фотохостинг, защищенное файловое хранилище и личный облачный диск.
