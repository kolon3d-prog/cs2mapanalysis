# Twinkle Tray — яркость внешних мониторов из системного трея

Оригинальный пост:

Twinkle Tray — яркость внешних мониторов из трея
Windows умеет регулировать подсветку экрана ноутбука, но с внешними мониторами разводит руками. Приходится тянуться к физическим кнопкам на корпусе и продираться через меню, которое разработчики монитора явно не тестировали на живых людях.
Twinkle Tray (https://twinkletray.com/) решает это за пару секунд. Утилита добавляет иконку в системный трей, а по клику показывает ползунки яркости для каждого подключённого монитора — ровно так же, как это работает со звуком.
Технически она общается с мониторами по протоколу DDC/CI, поэтому заодно умеет менять и другие параметры вроде контрастности. Ещё есть выравнивание яркости между разными экранами, чтобы одинаковые значения выглядели одинаково на панелях разных производителей.

Из приятного: яркость можно менять автоматически по времени суток или при простое компьютера, а также вешать на горячие клавиши — отдельно для конкретного монитора или сразу для всех. Оформление подстраивается под вашу тему и версию Windows, так что панель не выбивается из системы.

Программа бесплатная и с открытым кодом, поддерживает Windows 10 и 11. Скачать можно с сайта (https://twinkletray.com/), из Microsoft Store (https://www.microsoft.com/store/productId/9PLJWWSV01LK) или командой winget install xanderfrangos.twinkletray.
