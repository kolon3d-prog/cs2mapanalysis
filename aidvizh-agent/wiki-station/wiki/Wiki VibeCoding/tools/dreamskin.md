# DreamSkin — тюнинг десктопного Codex темами

Оригинальный пост:

🌈 DreamSkin (https://www.dreamskin.cc/) — ещё один "тюнинг" для десктоп Codex

Похожий проект, что и CodexThemes, но с своим фокусом: независимая сторонняя платформа для превью тем и "смены скина" приложения Codex.

✨ Фишки:

🖥 Сравнение прямо в браузере — можно сопоставить две качественные онлайн-концепции темы бок о бок, не устанавливая ничего
🖼 Мгновенный превью — загружаешь своё изображение или CSS и сразу смотришь, как будет выглядеть рабочее пространство
🎨 Студия создания — судя по связанным проектам (Codex Dream Skin), в основе — локальная инъекция через DevTools-подключение, которая накладывает CSS и декоративные элементы поверх интерфейса, не трогая сам app
🔄 Обратимость — тема снимается, оригинальный вид Codex восстанавливается без модификации самого приложения

⚠️ Важный момент:
проект неофициальный и не аффилирован с OpenAI — чисто community-инициатива по кастомизации внешнего вида.
