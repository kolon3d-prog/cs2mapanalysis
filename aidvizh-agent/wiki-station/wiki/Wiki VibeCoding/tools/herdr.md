# Herdr — терминальный мультиплексор для AI-агентов

Оригинальный пост:

Herdr — терминальный мультиплексор для AI-агентов, как tmux, только под агентов 🐑🖥

📊 Все агенты на одном экране: сразу видно, кто заблокирован, кто работает, кто закончил — реальные терминальные вью, а не пересказ от обёртки.

🔌 Детач/attach без потери сессии: закрыли ноут — агенты продолжают работать, подключиться можно с любого терминала или по SSH; сессии переживают рестарт.

🔗 Socket API для самих агентов: агенты могут сами спавнить пейны, читать вывод друг друга и ждать друг друга — не только человек управляет через UI.

⌨️ Клавиатура и мышь на равных: tmux-style префикс-клавиши плюс клик/драг/сплит — что удобнее в моменте.

🧩 150+ плагинов от комьюнити через маркетплейс — от файлового вьюера и ревью диффов до управления с телефона по Telegram или push-уведомлениям; маркетплейс — автоиндекс GitHub-топика herdr-plugin, без ручной модерации.

🦀 Один Rust-бинарник, никакого Electron — работает в любом терминале, который уже есть.

🚀 Установка:

curl -fsSL https://herdr.dev/install.sh | sh

или

brew install herdr

🔗 Сайт: herdr.dev
🔗 GitHub: github.com/herdrdev/herdr

## Контекст

- Пост готовый, ссылки не проверялись (по указанию автора).
- Что: мультиплексор агентов «как tmux»: все агенты на одном экране (реальные вью), detach/attach (SSH, переживает рестарт).
- Socket API: агенты сами спавнят пейны, читают вывод друг друга, ждут друг друга (агент-агентная координация).
- Управление: tmux-клавиши + мышь; 150+ плагинов (маркетплейс = автоиндекс GitHub-топика); один Rust-бинарник (без Electron).

## Вывод

Herdr — tmux для агентов (ср. ccmux — TUI над tmux для Claude Code, Pane — менеджер агентов с worktree). Ключевое отличие — Socket API: агенты координируются между собой, человек не обязателен в цикле. Rust-бинарник — лёгкость. Для команд агентов — практичный «общий экран».
