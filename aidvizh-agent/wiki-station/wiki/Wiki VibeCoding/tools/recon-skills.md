# Recon Skills — база знаний OSINT и пентеста от Offensive Security

Оригинальный пост:

💥 Recon Skills - база знаний по OSINT и пентесту от Offensive Security

Коллекция проверенных на практике методологий для анализа, оценки и тестирования на проникновение. Проект содержит структурированные техники, плейбуки и сценарии атак, которые помогут специалистам по безопасности проводить комплексный и легитимный аудит.

✨ Возможности и функции
• 🌐 Комплексные методологии анализа и оценки защищенности веб-ресурсов (Web Reconnaissance)
• 🔍 Поиск уязвимостей CORS, XSS, SQLi, SSRF, RCE, IDOR и аудит безопасности API
• 🧩 Готовые цепочки атак (attack chains) и плейбуки для многоэтапной эксплуатации
• ☁️ Техники компрометации облачных сред, Docker, WordPress и захвата поддоменов (subdomain takeover)
• 📖 Стандартизированные техники с примерами команд, способами верификации и разбором типичных ошибок
• 🛡 Встроенные рекомендации по обходу ограничений частоты запросов (rate limiting) и безопасной валидации уязвимостей
• 📚 Подборки Google dorks, инструменты OSINT и специализированные методики разведки под конкретные отрасли
• ⚙️ Модульная база знаний для интеграции в рабочие процессы Offensive Security
