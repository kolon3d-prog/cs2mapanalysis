# Cineprompt — конструктор промптов для ИИ-видео

Оригинальный пост:

Забираем конструктор промптов для ИИ-видео — киношники сделали удобный сервис, который сам собирает качественные запросы для генерации кино.

• Выбираете тип кадра, камеру, объективы и ещё кучу других параметров.
• Сервис оформляет всё в готовый промпт.
• Прога выдаёт промпт, адаптированный под нужную нейронку.

Делаем Absolute Cinema — cineprompt (https://cineprompt.io/)

## Дополнительный пост (повторный, тот же сервис)

Конструктор промптов для генерации видео с помощью ИИ, созданный кинорежиссёром.

Он позволяет выбрать формат медиа, жанр, настроение и звук, а также профессиональные параметры, которые используются на настоящих киносъёмках:

тип кадра, камеру, объектив, фильтры, освещение и многое другое.

Достаточно выбрать нужные параметры съёмки, и инструмент автоматически составит почти весь необходимый промпт для генерации видео, а затем оптимизирует его под конкретную модель.

https://cineprompt.io/

## Вывод

Пример «доменной экспертизы как сервиса»: киношные параметры → структурированный промпт. Экономит итерации подбора слов (ср. Cineprompt vs ручные промпты). Полезно для видео-генерации, если часто делаешь кадры «под кино».
