# 10 сайтов с референсами для дизайнеров

Оригинальный пост:

⚡️ Дизайнеры, это вам — 1️⃣0️⃣ крутейших сайтов с референсами для проектов: сотни мощнейших работ от профессионалов, стиль которых вы можете спокойно позаимствовать. Список:

1️⃣ mobbin.com — ТЫСЯЧИ экранов приложений для изучения паттернов привлекательности для юзера;

2️⃣ godly.website — гигантская галерея сайтов с сильным арт-дирекшеном;

3️⃣ awwwards.com — премия, которая выделяет сайты с мощнейшей реализацией;

4️⃣ cosmos.so — визуальная доска настроения, которая учится вашим предпочтениям;

5️⃣ curated.design — подборка страниц, организованная по категориям: портфолио, UI, оригинальный решение и тд;

6️⃣ designspells.com — каталог самых привлекательных и завораживающих деталей интерфейса;

7️⃣ 60fps.design — галерея, сосредоточенная на взаимодействии и качественной анимации;

8️⃣ supahero.io — только главные разделы вэб-сайтов, чтобы позаимствовать основную идею;

9️⃣ saaspo.com — лендинги SaaS с лучшими сайтами. Внутри есть фильтры для быстрой ориентации;

1️⃣0️⃣ layers.to — портфолио топового дизайнера, которого не найти в соцсетях.

Сохраняем и забываем про отсутствие идей.
