# tty7 — терминал на Rust, который переживает закрытие окна

Оригинальный пост:

tty7 — терминал на чистом Rust, который переживает закрытие окна 🖥⚡️

Устал терять сессию при закрытии терминала или тащить tmux только чтобы шелл не умирал вместе с окном? tty7 это чинит.

⚡️ GPU-рендеринг на gpui от Zed, VT-ядро — из Alacritty; по замерам авторов, cat 11 MB файла — 95ms, DOOM-fire бенч — 888fps.

🔄 Шелл живёт в фоновом daemon — закрытие окна, выход из приложения или обновление версии не обрывает сессию, tmux не нужен.

🖇 Из коробки: постоянные сессии, SSH, встроенная поддержка кодинг-агентов.

⌨️ Инлайн-автодополнение прямо в промпте с подсказками флагов и сабкоманд примерно для 100 популярных команд, плюс подсветка синтаксиса.

💻 Нативные сборки под macOS, Windows и Linux.

⭐️ 342 звезды на GitHub, Repository of the Day на Trendshift (25 июля 2026)
🔓 Apache-2.0, open source
