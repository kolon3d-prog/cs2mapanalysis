# Telegram-MCP — агент управляет твоим Telegram-аккаунтом

Оригинальный пост:

Telegram-MCP (https://github.com/chigwell/telegram-mcp) - агент управляет твоим акком

Короче, MCP-сервер, который дает любому агенту управлять твоим акком, например читать чаты, отправлять сообщения, САМОМУ отвечать на различные сообщения.

Как по мне - хорошо для автоматизации какого-то рабочего или саппорт акка, посадил иишку и не тратишь лишнее время, на основу не решился бы, ведь иишке дается фулл доступ к акку - всякое бывает, сами знаете

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: MCP-сервер для управления Telegram-аккаунтом агентом: чтение чатов, отправка сообщений, автоответы.
- Кейс из поста: автоматизация рабочего/саппорт-аккаунта («посадил иишку»).
- ⚠️ Риск, отмеченный автором поста: агенту даётся полный доступ к аккаунту — «всякое бывает».

## Вывод

Полезно для саппорт/рабочих аккаунтов, но доступ полный и необратимый по рискам: агент может ответить не то, утечь переписку или наделать дел. Паттерн безопасности: для таких сценариев — выделенный аккаунт с ограниченными правами, минимум чувствительных данных, логирование действий (принцип наименьших привилегий).
