# test-center

Сквозная проверка всей системы AGGG: гоняет то, что есть на этой машине, и при **первом же сбое**
пишет `багрепорт.md` — что именно запускалось, чем закончилось и что смотреть.

    bin/test-center.sh run                    прогнать всё, что доступно на этой ОС
    bin/test-center.sh run --only=smoke,wiki  только выбранные наборы
    bin/test-center.sh run --no-model         без живого запроса к модели
    bin/test-center.sh run --dry-run          план: какие наборы и пробы были бы запущены, без запуска
    bin/test-center.sh status                 что доступно: инструменты и наборы
    bin/test-center.sh report                 последняя запись багрепорта
    bin/test-center.sh clear                  убрать багрепорт
    bin/test-center.sh check                  предпосылки самой станции

На Windows — `bin/test-center.cmd` или `pwsh -File bin/test-center.ps1`; движок один (`bin/test.mjs`),
и он на node — поэтому работает на linux/macOS/Windows одинаково.

## Наборы

| набор | что проверяет | чем ограничен |
|---|---|---|
| `smoke` | центр (состояние, связи) + `check`/`verify` станций MCP, памяти, вики, коллекции скиллов | только node и bash |
| `wiki` | поиск по базе вики + **живой MCP-хендшейк** сервера вики (ждём 7 инструментов) + идемпотентность `wiki_index` (повторный вызов не трогает index.md и log.md) | node, python3 |
| `memory` | состояние памяти + MCP-хендшейк `basic-memory` | node, basic-memory |
| `bats` | наборы тестов, которые гоняет `center check` (сейчас 19 файлов, 407 тестов; не все наборы диска) | только linux/macOS: нужен `bats` |
| `model` | живой отклик модели: `omp -p "ответь ровно одним словом: ok"` | нужен `omp` и логин провайдера |
| `persona` | живые инварианты персоны: зан, «домен + e2e», личный оверлей, уточняющие вопросы на пустом вводе (4 запроса) | нужен `omp` и логин провайдера; отключается `--no-model` |

Наборы, которых на машине нет, **пропускаются**, а не падают: на Windows без `bats` прогон останется
зелёным, но в итоге будет видно, что пропущено.

`--dry-run` (в pwsh-обёртке — `-WhatIf`) печатает **план**: набор за набором, шаг за шагом, с командой
и её лимитом времени — и выходит нулём, не запустив ни одной команды и не обратившись к модели.
Набор, который был бы пропущен на этой ОС, в плане помечен этим честно; набор, шаги которого
собираются на ходу, вместо выдумки получает строку «без плана: &lt;набор&gt;». Машинный план — `--dry-run --json`.

## Багрепорт

Пишется в `багрепорт.md` рядом со станцией (путь меняется `TEST_CENTER_REPORT`). Внутри:

- когда, система (ОС/ядро/архитектура), версия набора, версии инструментов (node, python, bats, omp, pwsh, bash);
- набор и шаг, точная команда, код возврата (и пометка «таймаут»), что ожидалось;
- хвост stdout и stderr;
- раздел «Что проверить» — конкретные команды под этот шаг.

Записи **дописываются** (каждая — новый инцидент, разделитель `---`); `clear` удаляет файл.

## Чем отличается от `center check` и `doctor`

- `center doctor` — связи и регистрации (конфиги, симлинки, MCP), тесты не запускает;
- `center check` — все наборы bats (глубоко, только там, где есть bats);
- `test-center` — тонкая, но **переносимая** проверка: то же ядро работает и на Windows, где bats нет,
  плюс живой отклик модели, плюс MCP-хендшейки, плюс багрепорт с командой и хвостом вывода.

## Проверено на этой машине

- `run --only=smoke,wiki,memory` — 11 шагов, сбоев 0 ✓;
- `run --only=model` — модель ответила за 12 с ✓;
- `run --only=persona` — 4 инварианта зелёные: самоопределение, тестовая политика, оверлей, уточняющие вопросы (14.4 / 12.7 / 14.5 / 38.1 с) ✓;
- сбой шага (вики-MCP по несуществующему пути) — багрепорт записан с командой, кодом 1 и хвостом stderr ✓;
- `run --only=bats,model` с принудительно «отсутствующими» инструментами — наборы пропущены, код 0 ✓.

## Грабли

- `bats`-наборы требуют обычного PATH: если запускать с урезанным PATH, часть тестов упадёт на отсутствии
  инструментов — это не баг системы;
- `model` тратит реальный запрос (одно короткое слово) — отключается `--no-model`;
- `persona` тратит четыре живых запроса (≈15–40 с каждый) — отключается тем же `--no-model`;
- багрепорт — артефакт машины: в установочный архив не кладётся.
